# Slice Context Handoff

Use when changing IDE, model, computer, or when the user asks for handoff/checkpoint.

Recommended path:

```text
ai_workspace/context_handoff/YYYY-MM-DD_<topic>.md
```

Update indexes when available:

```text
ai_workspace/CONTEXT_INDEX.md
ai_workspace/AI_WORKSPACE_TOPIC_INDEX.md
```

Must include:

```text
1. Current branch/ref and workspace status.
2. Current objective.
3. Confirmed conclusions.
4. Rejected options.
5. Current State / Target State / Historical State / Pending Confirmation.
6. Related docs and code files.
7. Modified but unfinished files.
8. Build/test commands and results.
9. Next recommended prompt.
10. Sensitive data exclusions.
```
