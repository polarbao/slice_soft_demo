# Slice Context Handoff

Read `.agents/docs/context-handoff.md`.

Include:

- Project identity and branch/ref.
- Current objective and non-objectives.
- Evidence-backed facts.
- Key files and read order.
- Completed work and pending work.
- Validation status.
- Risks and unresolved questions.
- Next recommended prompt.

Never include secrets or unsupported validation claims.
