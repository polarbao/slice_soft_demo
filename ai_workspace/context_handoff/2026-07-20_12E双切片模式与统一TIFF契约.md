# 12E 双切片模式与统一 TIFF 契约交接

> 日期：2026-07-20
> 状态：TARGET CONTRACT PREPARED / IMPLEMENTATION BLOCKED

## 决策

正式目标提供两种端到端模式：

```text
slicePipeline.mode=legacy（默认）
slicePipeline.mode=global_surface_shell（显式）
```

模式不是 `slicingMode`、`texture.applyMode` 或 OpenVDB backend 的别名。

## 输出要求

两种模式一旦报告 production success，都必须通过现有共享 writer 生成完整 RGBWSV TIFF package，并保持：

```text
p0.rgbwsv.2；R G B W S V；uint8；black_is_print；
当前 preview、材料图层、报告和 package 目录规则。
```

Global 当前仍是 diagnostic/blocked，不具备生产 TIFF 能力。未 admitted 时必须阻断，不得静默回退 Legacy。
