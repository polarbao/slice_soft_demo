Build-specific note
-------------------

miniz is statically compiled into SliceSoft core libraries. meshoptimizer follows
the selected vcpkg triplet. LibTIFF is shipped by the default production build;
the explicit handwritten legacy verification lane does not ship LibTIFF.
Assimp is declared in vcpkg.json but is not linked by the current CMake target
graph. This notice includes Assimp in advance; shipping its binary later still
requires including its full license.

The release packaging step must copy this file and the complete licenses
directory. It must also regenerate the runtime dependency inventory and add
the notices of any newly shipped transitive dependency before publication.
