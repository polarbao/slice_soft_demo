## 2. 验收判据

1. 全仓文本文件**只有 LF**一种行尾，零混合——由脚本复核，不靠肉眼。
2. 每一波里，**未列入该波的文件一个字节都没动**。
3. 各波闸门的失败集合等于基线；涉及源码的波次，字节级基线 738 产物逐字节一致。
4. `.gitattributes` 生效后，新克隆检出的行尾唯一——换一台机器或换一个人不会重新长回来。

> 第 4 条是本专项与「清理一次」的根本区别。不做这条，前面八项迟早白干。

## 3. 与并行线的关系

若在对方落盘前转换这些文件，会与其未提交改动直接冲突。故：

- 上述文件在对方提交前**不纳入任何波次**。
