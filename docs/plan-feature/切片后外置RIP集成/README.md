| 专项 | 管什么 | 关系 |

## 5. 与缩裹专项的耦合点

[单材料缩裹整模识别与整版多实例](../单材料缩裹整模识别与整版多实例/README.md)
产出的是七通道 `p0.rgbwsvt.1` 包。在 D-10 之前，RIP 侧的输入准入**硬编码只认六通道
`p0.rgbwsv.2`**——于是缩裹包一进 RIP 就被拒，而报错指向的是"通道数不对"，
读起来像 RIP 库不支持，实际是切片软件自己的适配层没放开。

D-10 修的就是这件事。两个专项的交界面是**包协议**，不是代码：
缩裹侧只管产出合法的 `p0.rgbwsvt.1`，RIP 侧只管成对校验协议与通道布局。
