# RIP 模块 20260917、20260918 与 20260920 版本适配

本目录记录 RIP 供应方 `RIPDLL_20260917`、`RIPDLL_20260918`、`RIPDLL_20260920` 更新的分析、实施计划、任务状态和验证证据。

## 当前结论

- `RIPDLL_20260917` 修复 Windows 中文目录下 EXE 相对定位及 DLL 加载的 UTF-8/UTF-16 转换。
- `RIPDLL_20260918` 延续同一 CLI 源码和公开头文件，但 EXE/DLL 重新生成，DLL 实现发生二进制变化。
- `RIPDLL_20260920` 在上述基础上增加 `-v/--verbose`，默认过滤逐像素 `RIP_LOG_DEBUG` 日志。
- 三个新目录均不含 `CmykFiles`，不能直接替代完整的 `RIPDLL_20260909` 目录进行打包。
- 本次采用显式组合来源：20260920 提供 EXE/DLL/私有 TIFF，20260909 提供最近一次已纳入项目验证的完整 `CmykFiles`。
- 供应方 `rip_slicer.h` 未变化；切片侧保持进程外 QProcess 集成，不改 ABI、RGBWSV 输入合同和现有 RIP 设置语义。
- 小型真实输入实测 0917 与 0918 输出一致；0920 的 `ripMode=0` 输出一致，但 `ripMode=1` 输出哈希变化，故仍需完整宿主矩阵验证。
