## 1. 产品目标

00C 阶段用于解决单材料浮雕模型在当前 P0 Demo 中的切片异常问题。

目标是：

```text
OBJ/STL 浮雕模型
→ relief_heightfield 切片模式
→ 单材料通道输出
→ RGBWSV uint8 TIFF
→ 0=打印，255=不打印
```

当前业务场景中，浮雕模型是高频输入类型，因此 00C 优先级高于彩色纹理阶段。
