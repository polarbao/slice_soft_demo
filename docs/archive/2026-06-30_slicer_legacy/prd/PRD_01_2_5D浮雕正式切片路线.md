# PRD_01_2_5D浮雕正式切片路线

> 文档版本：v0.1  
> 文档状态：Draft / PRD  
> 适用阶段：00C 完成后 / Milestone 01  
> 所属模块：Slicer / Relief  
> 建议提交目录：`docs/slicer/`

---

## 1. 背景

00C 已实现 `relief_heightfield` 简化浮雕路径，并完成单材料 V 光油与 S 支撑联合输出。

当前能力仍属于 P0+ Demo：

```text
对三角面按 XY 覆盖像素进行列采样
每个 XY column 记录 z_min / z_max
surface_to_base / intersection_range
V 光油模型材料
S 下表面支撑
```

PRD_01 的目标是将该能力升级为正式 2.5D / Relief 产品路线。

---

## 2. 产品目标

PRD_01 目标：

```text
为美甲甲片、浮雕件、浅浮雕装饰件提供正式的 2.5D / Relief 切片能力。
```

支持：

```text
1. relief_heightfield 正式切片模式
2. 单材料 V / W / RGB 输出
3. 下表面支撑
4. 高度场诊断
5. relief 专用报告
6. relief 专用测试模型集
7. 多种材料应用模式的阶段定义
```

---

## 3. 用户场景

### 3.1 美甲甲片浮雕

```text
输入：OBJ / STL 拱形甲片模型
材料：光油 V
支撑：下表面 S
输出：RGBWSV TIFF
```

### 3.2 单材料白墨浮雕

```text
输入：OBJ / STL 浮雕模型
材料：白墨 W
支撑：可选 S
输出：RGBWSV TIFF
```

### 3.3 单材料 RGB 浮雕

```text
输入：OBJ / STL 高度起伏模型
材料：RGB 单色/灰度
支撑：可选 S
输出：RGBWSV TIFF
```

## 4. 功能范围

### 4.1 必须支持

```text
slicingMode = relief_heightfield
relief.fillMode = intersection_range
relief.fillMode = surface_to_base
modelMaterial.materialChannel = V / W / RGB / auto
modelMaterial.applyMode = solid_volume
support.enabled = true / false
preview.channels = varnish / support / white / rgb
manifest.slicing
relief_report.json
```

### 4.2 新增建议能力

```text
relief.modelTypeHint
relief.heightFieldDiagnostics
relief.columnCoverageReport
relief.thicknessRangeReport
relief.invalidColumnPolicy
relief.testModelProfile
```

---

## 5. 材料语义

继续遵守 00B：

```text
uint8
0 = 打印
255 = 不打印
R G B W S V
```

### 5.1 V 光油模型

```text
模型区域：V = 0，其余未使用通道 = 255
支撑区域：S = 0，其余未使用通道 = 255
```

### 5.2 W 白墨模型

```text
模型区域：W = 0，其余未使用通道 = 255
支撑区域：S = 0，其余未使用通道 = 255
```

### 5.3 RGB 模型

```text
模型区域：R/G/B = 配置值，W/S/V = 255
```

---

## 6. 支撑需求

PRD_01 继续支持当前 bottom_projection：

```text
对每个 XY column：
  找到模型下表面 layer
  下表面以下到平台之间写 S 通道
```

PRD_01 不做复杂支撑树，但必须输出：

```text
support_report.json
每层 supportPixels
support preview
```

---

```text
supportPixels
```

---

## 9. 验收标准

1. 普通 closed_mesh_scanline 样例不受影响。
2. relief_heightfield 样例可稳定运行。
3. V 光油 + S 支撑样例通过 RIP reader。
4. W 白墨样例可输出 W 通道。
5. RGB 样例可输出 RGB 通道。
6. relief_report 记录高度场统计。
7. support_report 记录支撑统计。
8. Preview 可查看 V / S / W / RGB。
9. Manifest 记录 slicing.mode 和 reliefFillMode。
10. 仍保持 uint8 / black_is_print / R G B W S V。
