## 3. Target State

已接受的双模式目标：

~~~text
slicePipeline.mode = legacy | global_surface_shell
default = legacy
~~~

两条模式在生产材料层形成前分叉，成功准入后共享：

~~~text
RGBWSV TIFF writer
p0.rgbwsv.2 manifest
preview/report/package 目录
rip_reader_test
~~~

Global 状态机：

~~~text
unavailable -> blocked -> diagnostic -> admitted
~~~

未 admitted 时不能写可使用 TIFF。Global 失败不得静默 fallback 到 legacy；用户必须显式重新选择 legacy 并发起新的运行。

## 6. 产品级后续方向

在完成当前阻断后，正式 Host Software 仍需要：

- 作业/项目管理、队列和取消恢复；
- 设备与材料 Profile 生命周期；
- 输入资产质量管理和人工修复闭环；
- 更完整的多模型/排版决策；
- 性能预算、缓存和增量重算；
- 版本化输出兼容与下游交付；
- 安装、升级、日志、崩溃恢复和可观测性；
- 与 RIP/设备团队建立独立接口和真机验收；
- 安全、权限、审计和客户资产保护。

这些不应被一次大重构同时实现，应按明确 PRD、Decision、阶段 Gate 和可回退的小任务推进。
