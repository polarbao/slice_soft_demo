# 02 术语表

## 1. 打印与输出

| 术语 | 中文解释 | 在本项目中的含义 |
|---|---|---|
| DPI | 每英寸像素/点数 | 决定 XY 像素尺寸，`pixelSizeMm=25.4/DPI` |
| Layer Thickness | 层厚 | Z 方向采样间隔，单位 mm |
| RIP | 光栅图像处理 | 下游消费切片包；本仓库不实现完整 RIP |
| TIFF | 标签图像文件格式 | 每层六通道生产数据容器 |
| RGBWSV | 六通道协议简称 | R、G、B、White、Support、Varnish |
| black_is_print | 黑值表示打印 | 当前协议中 0 为打印值、255 为空值 |
| Stripped | 条带存储 | TIFF 按若干行组织 |
| Tiled | 瓦片存储 | TIFF 按二维 tile 组织 |
| Manifest | 清单 | 描述协议、网格、层文件和报告路径 |
| Preview | 预览 | 供人观察的 PNG/PPM 或伪彩，不替代生产 TIFF |
| Golden | 金标摘要 | 稳定、可比较的预期输出或投影 |

## 2. 模型与几何

| 术语 | 解释 |
|---|---|
| Mesh | 由顶点、边和三角面组成的网格模型 |
| Triangle | 当前几何处理的基本面元 |
| Bounding Box / BBox | 模型在 X/Y/Z 的最小包围盒 |
| UV | 将三角面位置映射到二维纹理图的坐标 |
| MTL | OBJ 常用材质描述文件 |
| 3MF | ZIP 容器形式的 3D 制造格式，可携带对象、变换、颜色和纹理资源 |
| Closed Mesh | 理想闭合网格，每条流形边通常被两个面共享 |
| Boundary Edge | 只连接一个面的边，常表示开口 |
| Non-manifold Edge | 邻接关系不满足二维流形假设的边 |
| Degenerate Triangle | 面积接近零的退化三角形 |
| Winding | 三角面顶点顺序，用于表达法向方向 |
| Self-intersection | 网格面之间不应出现的自相交 |
| Occupancy | 体素/网格点是否属于模型内部 |
| SDF | 有符号距离场，通常以符号表示内外、绝对值表示距表面距离 |
| Voxel | 三维离散单元 |
| Raster | 二维像素网格 |
| Scanline | 按扫描行求交并填充跨度的栅格方法 |
| Heightfield | 每个 XY 列以高度/区间描述实体的 2.5D 表达 |

## 3. 材料与策略

| 术语 | 解释 |
|---|---|
| MaterialRoleMapping | 把输入材质名称映射到 rgb/white/varnish/support/ignore 等角色 |
| MaterialPolicy | 选择 RGB、白墨、光油的启用、模式和冲突策略 |
| MaterialProcessProfile | 面向特定工艺的组合参数与验收要求 |
| Model Fill | 纹理表层之下的模型内部填充材料 |
| Texture Surface | 携带纹理颜色的模型表面区域 |
| Surface Shell | 根据表面距离定义的壳层 |
| Global Surface Shell | 对全部闭合表面使用完整三维距离定义壳层 |
| Underbase | 彩色区域下方的白色底层语义 |
| Varnish | 光油/透明材料，通道 V |
| Support | 支撑材料，通道 S |
| SupportType | 支撑形成原因，仅用于元数据/报告/调试 |
| Priority Resolver | 多个语义命中同一位置时的确定性优先级 |
| Fallback | 缺纹理、缺 UV 等情况下显式采用的替代颜色/策略 |

## 4. 诊断与准入

| 术语 | 解释 |
|---|---|
| Diagnostic-only | 只允许观察和取证，不能当生产结果 |
| Candidate | 候选实现或候选证据，尚未完成生产准入 |
| Production Admission | 判断某结果能否进入生产输出的门禁 |
| strict_closed | 对闭合性、流形、绕序、自交等采用严格阻断 |
| warn_and_attempt | 允许尝试诊断，但不能标记 production-safe |
| repair_then_strict | 显式修复后重新跑完整 strict；不能复用修复前结论 |
| Fail Fast | 确认严重问题后立即停止，不生成误导性生产结果 |
| Blocker Code | 稳定的机器可读阻断码 |
| Exact | 基于语义 mask 的精确证据 |
| Candidate Confidence | 从最终 TIFF 反推的候选证据，不能代替 exact |
| Material Closure | 预期占据域内材料是否连续、互补且无未解释空洞 |
| Invariant | 算法或数据必须始终满足的不变量 |
| Determinism | 同一输入和配置应产生一致结果与稳定 tie-break |

## 5. 工程与项目治理

| 术语 | 解释 |
|---|---|
| Legacy | 当前稳定生产实现，不表示可以随意删除的“旧代码” |
| Experimental | 显式实验路径，默认不进入生产 |
| Feature Gate | 用构建/配置开关隔离能力 |
| DTO | 跨模块传递的数据结构，不携带隐式 I/O 或 UI 依赖 |
| Schema | 配置、报告或包的数据契约版本 |
| Fixture | 为复现某种行为构造的测试输入 |
| Smoke Test | 快速确认主要入口和界面可启动/运行 |
| Regression | 防止既有行为被新改动破坏的回归测试 |
| Current State | 当前代码事实 |
| Target State | 已设计或已批准的目标 |
| Historical State | 只用于解释演进的历史状态 |
