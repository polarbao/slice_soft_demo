# 08 纹理、支撑、光油与材料闭环

## 1. 纹理应用策略

当前代码保留四个正式策略枚举：

~~~text
FullVolume
SurfaceShell
TopSurfaceOnly
OuterSurfaceShell
~~~

legacy 配置中常见：

| applyMode | 语义 |
|---|---|
| `solid_volume_from_top_surface` | 从上表面颜色沿模型列扩展 |
| `top_surface_only` | 只在顶表面 |
| `top_surface_band` | 顶部若干层 |
| `surface_shell_from_sdf` | 历史 OpenVDB candidate，必须显式 experimental |
| `global_surface_shell` | 12E 完整三维壳层诊断 |

不要用 `texture.applyMode` 代表整条端到端 pipeline。未来正式模式字段是独立的 `slicePipeline.mode`。

## 2. 纹理采样

当前纹理相关配置包括：

- `sampler=nearest|bilinear`；
- `uvAddressMode=clamp|repeat`；
- `flipV`；
- `fallbackRgb`；
- `missingTexturePolicy=warn_and_fallback|fail_fast`；
- `nonSurfaceRgbPolicy`。

Surface shell 纹理转移的关键规则：

- 最近表面引用必须稳定；
- 使用命中三角形自己的 UV；
- 不跨 UV seam 平均；
- 不跨 material seam 混色；
- tie-break 必须确定；
- missing UV/resource/sample 必须有可读 issue 和 fallback 统计。

## 3. Global Surface Shell 的互补分区

目标语义：

~~~text
ModelMask = TextureSurfaceMask ∪ ModelFillMask
TextureSurfaceMask ∩ ModelFillMask = ∅
OutsideModel 两者都为 0
~~~

纹理壳层宽度按到全部闭合表面的三维距离判断，不是只看顶面 Z 深度。宽度增加时：

- texture voxel 数应非递减；
- fill voxel 数应非递增；
- model voxel 数不变；
- 达到动态模型上限时可成为 all-texture；
- 每个采样点仍应满足 exact partition。

当前 12E 已建立 CPU candidate、OpenVDB conformance、width sweep、纹理转移、raster mapping 和 full closure 诊断，但尚未进入生产 writer。

## 4. 支撑

### Placement

`support.placement` 描述 lower、upper、both、unsupported_only、full_vertical_projection 等有效策略。旧配置未显式 placement 时存在兼容解析，报告会区分 requested/effective。

### Internal Void

`support.internalVoid` 处理模型内部封闭空洞的支撑需求，受 `minAreaPx` 和 fill rule 约束。它与外部背景不同，材料闭环必须使用 ExpectedOccupiedDomain 区分。

### Shape Optimization

`support.shape` 可过滤小组件、膨胀、闭合小缝和 bridge。`preserveModelPriority` 与 `maxAddedSupportRatio` 防止优化无限扩大或侵占模型。

## 5. 光油

### 模型内/表面光油

- MaterialPolicy/Profile 可以在 all_model 或 top_n_layers 写 V；
- `surfaceVarnish` 可选择 outer/inner surface 和厚度；
- V 可以与 RGB/W 共存还是互斥，必须由工艺策略和报告明确。

### 外侧光油

`outerVarnish` 可能在模型外扩张，配置包含物理厚度、步长、像素 pitch、是否允许 XY 扩张、冲突策略和值。它会影响 GridSpec padding，不能只在合成末尾随便涂一圈。

### Varnish Geometry Target

正式策略枚举还保留：

~~~text
InPlaceTopLayers
AdditiveGrow
CompensatedShrink
~~~

`CompensatedShrink` 是目标/实验方向，不应被写成当前 production 能力。

## 6. 材料闭环的五类问题

12D exact 检测围绕：

1. ColorFillGap：纹理颜色与模型填充之间的缝；
2. ModelSupportGap：模型与所需支撑之间的缝；
3. ColorSupportGap：颜色材料与支撑关系异常；
4. InternalVoidGap：内部空洞应填支撑但为空；
5. VarnishSupportGap：光油边界与所需支撑之间的缝。

候选 detector 可从 TIFF 反推邻接，但 exact detector 使用语义 mask。生产验收必须使用 exact。

## 7. 一像素修复

当前材料闭环 repair：

- 默认关闭；
- 只有 `mode=repair_then_report` 与 `repair.enabled=true` 成对时生效；
- `maxGapPx` 必须为 1；
- 修复规则固定并经过配置校验；
- 必须保护 ExternalBackgroundMask；
- 必须限制在 ExpectedOccupiedDomain；
- 2px 及以上只报告，不修；
- 应用后重算 remaining gap；
- 报告 repaired/rejected/remaining 分类统计。

这与 mesh topology repair 是两件事：前者修材料栅格的一像素缝，后者修三角网格拓扑。

## 8. 生产判定的完整链

~~~text
输入拓扑 strict
-> 几何/分区不变量
-> 纹理属性与 fallback
-> classification-to-raster
-> support/varnish/material full closure
-> RGBWSV writer
-> manifest/TIFF strict reader
-> Release 性能和内存
-> 真实模型证据
~~~

任意一段 diagnostic pass 都不能代表整条链 production pass。
