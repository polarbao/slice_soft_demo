# SliceSoft 从零到参与开发教程

> 教程版本：v1.0
> 基线日期：2026-07-20
> 面向对象：第一次接触 UV 工业喷墨 3D 打印、第一次进入本仓库，以及准备参与后续开发的产品、算法、应用、测试和架构人员

## 1. 这套教程解决什么问题

正式文档按 PRD、DEV、DEMO、ROADMAP、REPORT 和决策记录组织，适合查证；本目录按学习顺序组织，适合从零建立完整心智模型。

你将依次理解：

1. 项目为什么存在，以及它在打印系统中的位置；
2. 3D 模型、切片、纹理、材料、支撑、光油和 RGBWSV 的基本原理；
3. 当前代码真实实现、正式目标设计和历史实验之间的差别；
4. 配置如何驱动导入、几何、材料、输出、报告和 UI；
5. 如何构建、运行、验证、定位问题并提交一个合格改动；
6. 当前阶段已经完成什么、仍被什么阻断、后续应如何演进。

## 4. 教程的事实边界

本教程遵循项目证据等级：

- **A 当前实施基线**：当前代码、CMake、脚本、测试和样例，可作为实现依据；
- **B 正式目标设计**：`docs/slice` 下的 PRD、DEV、ROADMAP 和决策，表示方向，不自动证明已实现；
- **C 历史资料**：归档文档、旧报告、聊天和已完成任务，只补充背景；
- **D 废弃或冲突资料**：只用于追溯，不能作为实现依据。

当教程与当前代码发生冲突时，以代码、CMake、脚本和最新带证据的报告为准，并修订教程。

## 5. 当前最重要的安全结论

截至基线日期：

- `legacy` 是默认、已存在的生产包路径；
- `global_surface_shell` 已具备分区、纹理传递、栅格映射和完整材料闭环诊断，但仍不是生产路径；
- 未来目标是 `slicePipeline.mode=legacy|global_surface_shell`，该 Router 和 UI 生产选择器尚未实现；
- OpenVDB 是可选能力，默认关闭，不是普通构建的强制依赖；
- RGBWSV 协议固定为 `p0.rgbwsv.2`、`R G B W S V`、8 位和 `black_is_print`；
- 本项目提供 `rip_reader_test` 做包契约验证，但不实现完整 RIP 半色调、ICC、喷头 bitstream 或设备通信。
