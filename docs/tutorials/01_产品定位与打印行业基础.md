# 01 产品定位与打印行业基础

## 1. SliceSoft 在整套打印系统中的位置

SliceSoft 是 UV 工业喷墨 3D 打印的上位机切片原型。它把三维模型与材料意图转换为按 Z 层排列的二维材料通道图，并生成可交付给下游 RIP/设备团队的包。

~~~mermaid
flowchart LR
  A["设计资产<br/>OBJ/STL/3MF/纹理"] --> B["SliceSoft<br/>几何切片与材料语义"]
  B --> C["RGBWSV TIFF 包<br/>manifest / reports / preview"]
  C --> D["下游 RIP<br/>色彩、半色调、设备映射"]
  D --> E["设备控制<br/>喷头时序与运动"]
  E --> F["打印件与质量检测"]
~~~

本仓库覆盖 B 和 B->C 的交付契约，也提供一个严格包读取器验证 C。它不覆盖完整的 D、E 和 F。

## 2. 什么是切片

三维模型是连续几何，打印设备按离散层工作。切片包含三个离散化过程：

1. Z 方向按 `layerThicknessMm` 分层；
2. XY 方向按 `dpiX/dpiY` 转为像素网格；
3. 每个像素根据模型、纹理、填充、支撑和光油策略写入材料通道。

600 DPI 时单像素理论尺寸约为：

~~~text
25.4 mm / 600 ≈ 0.04233 mm = 42.33 μm
~~~

层厚、DPI 和模型尺寸共同决定层数、像素数、内存、耗时和细节上限。

## 3. UV 喷墨与常见熔融沉积打印的差别

本项目的输出不是单一轮廓或单材料 G-code。它需要表达多个材料平面：

- RGB：彩色/纹理相关通道；
- W：白色材料或白墨填充；
- S：支撑材料；
- V：光油/透明材料。

因此核心问题不仅是“哪里有实体”，还包括“每个位置应使用何种材料、是否互斥、是否连续、是否允许空白”。

## 4. RIP 是什么，本项目做到哪里

RIP 通常负责把高层图像/材料数据进一步转为设备可执行数据，可能包含色彩变换、墨量限制、半色调、喷头通道映射、校准和设备参数。不同设备的具体职责会不同。

本项目当前只冻结上游交付契约：

~~~text
RGBWSV TIFF + manifest + reports
~~~

`rip_reader_test` 验证包结构、schema、通道、位深、极性、网格、层列表和 TIFF 存储，不等于完整 RIP，更不等于真机打印验证。

## 5. 为什么需要支撑和光油

### 支撑

支撑材料为悬空、底面、内部空洞或可拆区域提供制造支撑。项目将支撑原因记录为 `SupportType`，但生产 TIFF 中仍只有一个 S 通道。原因信息存在报告/调试数据中，不能塞进 S 通道取值。

### 光油

光油既可能覆盖模型表面，也可能形成模型外侧附加壳层。两种语义必须分开：

- `surfaceVarnish`：写在模型表面像素上的 V；
- `outerVarnish`：模型外侧的附加 V 壳层，可能扩展 XY 边界。

## 6. 为什么“能出图”不等于“能生产”

生产准入至少要回答：

- 模型拓扑是否足够闭合、无非流形和严重自交；
- 材料域是否互补、无意外孔洞和冲突；
- 输出协议是否完全一致；
- 配置、输入、报告和结果是否可追溯；
- Release 性能和内存是否满足冻结预算；
- 失败时是否明确阻断，而非静默回退。

这正是本项目大量 diagnostics、report、golden、RIP reader 和 admission policy 存在的原因。

## 7. 产品角色

| 角色 | 主要关注 |
|---|---|
| 工艺工程师 | W/S/V 语义、覆盖率、层分布、材料优先级 |
| 算法工程师 | 几何、拓扑、距离场、栅格、纹理转移 |
| 应用/UI 工程师 | 配置、任务执行、预览、报告和错误呈现 |
| QA | fixture、golden、负向包、真实模型、回归矩阵 |
| 架构师 | 模块边界、协议稳定、可选依赖和演进风险 |
| 下游 RIP/设备团队 | 输入包契约、层顺序、通道语义和兼容性 |

## 8. 当前产品边界

已具备的是工程化切片原型和调试工作台，不是完整商业 Host Software。作业队列、设备管理、ICC、半色调、喷头 bitstream、设备通信、完整 3D 修模与真机闭环仍在项目边界之外或未来阶段。
