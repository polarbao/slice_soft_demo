# 新版宿主鼠标滚轮交互规则

更新：2026-09-14。对应 HOSTUX UX-11/12，UX-12 恢复标签栏滚轮导航。

滚轮用于浏览和视图导航，不用于修改切片、排版或 RIP 参数。

| 鼠标所在位置 / 状态 | 滚轮行为 |
|---|---|
| 工作区 2D / 3D 画布，已加载模型且未按下鼠标键 | 保留以鼠标位置为中心的缩放 |
| 正在拖动模型、中键平移或拖动旋转视角 | 暂停滚轮缩放，避免拖动时误转滚轮 |
| 空画布 | 不缩放 |
| 设置页、模型列表、报告或日志的滚动区域 | 保留正常滚动浏览 |
| 已打开的下拉列表 | 滚动浏览选项，点击或按确认键选择 |
| DPI、层厚、XYZ、排版、支撑、材质、RIP 等数值输入框 | 不通过滚轮改变数值；有上级滚动区域时滚动页面 |
| 未展开的工艺、预设、通道、相机等下拉框 | 不通过滚轮更换选项；有上级滚动区域时滚动页面 |
| 标签页标题 | 允许滚轮前后切换页面，包括 RIP/变换内的分组标签；参数区滚动不会切换标签 |
| 结果生产层滑条、层号输入框 | 不通过滚轮跳层；使用拖动滑条、层号输入或方向键选择 |
| 结果预览的滚动区域 | 有溢出内容时正常滚动图片，不切换层号或通道 |

输入框即使刚点击过、仍拥有键盘焦点，也不会被滚轮改值。
直接输入、点击数值框增减箭头、键盘方向键、滑条拖动和中键拖动画布继续有效。
当控件没有上级滚动区域，或页面已经滚动到边界时，滚轮不会再触发其他参数操作。

该规则仅影响宿主 UI，不改变模型摆放、切片算法、TIFF 像素、通道协议或 RIP 工艺。

## 右侧页面滚动

取消整组标签外层的统一滚动条，标签栏始终固定；每个页面独立管理滚动范围。

| 页面 | 显示方式 |
|---|---|
| 模型、工艺配置 | 常规窗口不需要页面级滚动条；列表、预检表和说明文本仍可内部滚动 |
| RIP 设置 | 按「参数 / 路径 / 手动 RIP」分页，常规窗口无需页面滚动条；底部状态和自动 RIP 操作保留 |
| 变换 | 只剩实例变换，不再分页，常规窗口无需页面滚动条（「导入与排版」已迁往「模型」页） |
| 切片设置 | 参数多且可展开，保留按需滚动条 |
| 切片作业 | 计时、状态和诊断信息超出当前高度时才滚动 |

小窗口、高缩放或长诊断信息导致内容确实放不下时，仍会按需出现滚动条，避免输入框和按钮被裁剪。
改变分组或页面不会重置已输入的参数。
