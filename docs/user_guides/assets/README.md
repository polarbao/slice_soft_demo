# 使用手册截图资产

本目录保存切片软件使用手册引用的界面截图。截图只用于说明主要操作入口，
功能状态仍以对应分支的当前代码和任务清单为准。

## 整版缩裹配图（2026-09-20）

**这两张不是界面截图，是产品产出的通道平面渲染。** 本目录其余图片均为 Qt 界面
抓图，此处特别注明以免混淆：它们不是软件里能看到的画面，而是切片产出的 TIFF
层里某一个通道的成像。

| 文件（packaged_slicer 下） | 内容 | 像素 |
|---|---|---|
| 28_整版缩裹单层T平面.png | 一版 12 件的第 3 层 T 通道平面，全画幅；同层 R/G/B/W/S/V 六通道打印像素为 0 | 1004 x 126 |
| 29_光油V与缩裹T同形对照.png | 同版同层：上半为单材料光油的 V 平面，下半为整模缩裹的 T 平面，各 8826 个打印像素、逐像素相同 | 1004 x 260 |

采集方式：直接读切片写出的 TIFF（无压缩、条带式、8 位、contiguous），取其中一个
通道的平面成像；`black_is_print`，故黑色即打印。**未重绘、未做像素编辑**，
仅把非空值映射为黑、空值映射为白，并在图二中把两个平面上下拼接（中间留 8px 白边）。

原始证据：`monowrap_plate_transfer_vs_varnish_tests` 这一条 ctest 的产出包，
位于 `%TEMP%/slicesoft_monowrap_plate/{wrap,varnish}/package/layers/layer_000003.tiff`。
该用例断言两个平面逐像素相同，图二是那条断言的可视化。

**取值口径**：该用例跑在**粗网格**上（150 dpi、0.2mm 层厚），因为它验的是
「通道落点」这条不变量，与分辨率无关。故图中尺寸不代表产线分辨率下的画幅。
图示仅说明通道归属与整版合成，不代表全仓回归、全部真实模型或物理打印验收。

| 20_T工艺补齐X原点.png | T 按需补白预设下勾选补齐至 X=0 | 378 x 231 |

使用独立 `--manual-guide-self-test` 实例，现有工作区持久化规则使截图设置不写回用户偏好。
`scripts/CaptureSliceGuideScreenshots.ps1` 校验 PID/命令行，并按同进程主窗口标题定位，
避免 Qt 下拉弹窗被误当成主窗口。支持 Prepare、Inspect、Invoke、Click、Toggle、Focus、Capture；
Capture 用控件名称确定上边界与宽度，可用 BottomControlName 延伸到另一个控件的下边界。
Prepare 调整专用窗口及右侧面板宽度，会操作鼠标，应在桌面空闲且窗口无遮挡时取图。
脚本不是离屏渲染器；每张图仍需实际查看，不能把返回文件路径当作视觉检查通过。

图 18 的关闭状态是保留源坐标的操作示例，不是产品初始默认值。图 19 未选择实例，故提交按钮禁用。
图 20 的完整预设名已通过 UI Automation ValuePattern 核对为“彩色纹理｜全实体 RGB + 按需补白墨｜下表面支撑｜缩裹 T 通道”；
截图保留窄面板原有的名称截断，不伪造完整标签。以上图片仅证明控件状态，不代表本轮重新完成真实模型切片或打印验收。
