# SliceSoft 更新公告

2026年9月14日

本次更新主要改善模型选择、参数操作和工艺切换体验：

- **选中更清楚**：二维、三维视图与模型列表联动，选中模型显示蓝色外轮廓；修正透明图案内部出现大量黄色描边的问题。
- **三维操作更顺手**：调整鼠标拖动旋转方向，以鼠标按下位置为旋转中心；加粗原点坐标轴并标注 X/Y/Z。
- **参数显示更完整**：优化高分辨率输入框，右栏可拖宽；RIP 和变换排版按子标签分组，内容过多时按需滚动。
- **减少滚轮误操作**：参数框、未展开下拉框和层滑条不再随滚轮改变数值；保留标签切换、列表滚动及画布缩放，拖动过程中暂停缩放。
- **工艺切换更连贯**：支持导入后切换工艺并保留模型摆放；补齐多图层预设参数的保存和恢复。无法开始切片时，作业页和按钮提示会显示具体阻断原因。
- **RIP 状态更直观**：显示处理阶段、累计耗时和已出现的输出文件数；手动 RIP 默认使用最近切片目录，并自动准备独立输出目录。
- **启动与帮助更新**：程序入口简化为 `slice_soft_test.exe`，旧名称仍兼容；用户手册同步更新操作说明和界面配图。

更新后请启动正式运行目录中的 `slice_soft_test.exe`。已有切片输出保留；RIP 文件计数仅表示文件已出现，最终是否成功以输出校验结果为准。
