# SliceSoft 更新公告

2026年9月21日 ｜ 0.2.532-dev

本次更新的重点是新增整模缩裹工艺，并让它支持一版多件：

- **新增「单材料缩裹｜整模 T 实体｜下表面支撑」工艺**：整个模型都识别为缩裹材料，只写 T 通道，R/G/B/W/V 保持空。它与原有「｜缩裹 T 通道」系列的区别是**不按材质颜色匹配**，因此无 mtl 的纯几何模型也能用，也不要求模型流形或无自交——此前因拓扑被拒的资产，改用这条工艺可以正常切片。
- **整模缩裹支持一版多件**：同一版面可排多个模型，一次切成**一个**包，画幅取整版最大外包围区域，与单材料光油、白墨一致。此前该工艺限定版面上只能有一个模型，多于一个会直接失败。使用时注意两点：同一层上各模型的投影不得相交；版面至少要有一个可见模型。同版面下耗时比单材料光油约高两成，属正常现象，不需要调整参数。
- **导入落位开关移到「模型」页**：与「添加模型」同处一页，不必再切到别的页去改。
- **修复自动 RIP 进度不可见**。
- **缺少贴图不再静默降级**：改为明确失败并给出原因，避免拿到一个看似成功但内容不对的结果。
- **损坏或被截断的 TIFF 处理更稳**：解码前先按文件实际大小核对声明的宽高与通道数，不再先分配内存再校验。
- **RIP 运行模块更新至 0920 版本**：设置项与使用方式不变。

更新后请启动正式运行目录中的 `slice_soft_test.exe`，已有切片输出保留。

用整模缩裹切整版时，建议先用同一版面换「单材料光油」切一次作参照：两者打印像素的几何应当完全一致，差别只在落到 V 还是 T 通道。这是核对有没有模型漏切最省事的办法。
