# PRD 13B-08 批量导入与当前场景一键切片

> 文档版本：v1.1
> 文档状态：APPROVED
> 日期：2026-07-28
> 对应决策：`DOC_DECISION_13B_08_场景作业流与13D工作台收口优先级.md`
> 批准记录：2026-07-28，用户授权进入 13B-08 开发

## 1. 问题

用户已经可以在俯视工作区中看到多个模型、调整变换并执行规则排版，但当前仍缺少完整作业闭环：

```text
导入模型一次只能选一个文件；
场景存在实例时旧“运行切片”被主动禁用；
“导入模型并切片”会重新选择单个文件，不消费当前场景；
三模型场景无法从界面直接产生一个联合 RGBWSV Package。
```

## 2. 产品目标

### 2.1 批量导入

一次文件选择允许导入多个 `OBJ/STL/3MF`。导入后：

```text
每个文件创建独立 instance；
按本次选择顺序稳定入队；
同源模型资源允许复用，但 instance identity 必须独立；
成功项保留，失败项明确列出；
批次完成后只执行一次规则排版；
场景总实例数不得超过 22。
```

### 2.2 当前场景主切片动作

模型工作区必须始终显示主按钮：

```text
切片当前场景
```

按钮不再打开模型文件对话框。它消费当前可见 SceneDocument、当前变换、当前规则排版、当前
Profile 和显式选择的生产模式。

按钮状态：

| 状态 | 表现 |
|---|---|
| 无模型 | 禁用，提示“请先导入模型” |
| 正在批量导入/投影 | 禁用，显示当前进度 |
| 场景有未保存变换 | 可点击；点击后自动生成不可变 Effective Config，不要求用户先手工保存 |
| 预检未完成 | 点击后先执行场景预检，不直接启动切片 |
| 任一可见实例阻断 | 禁用或预检后阻断，列出 instanceId 和错误码 |
| 场景碰撞/越界 | 阻断，不生成 Package |
| 所选模式不支持场景生产 | 阻断，不静默回退 Legacy |
| 已准入 | 启动联合切片并显示阶段进度 |
| 成功 | 自动加载单一 Package 并切到生产预览 |

### 2.3 输出

```text
一个场景只产生一个 package；
每个 layerIndex 只产生一个 RGBWSV TIFF；
manifest 包含 scene extension；
reports/multimodel_scene_report.json 可追踪 modelId/instanceId；
RIP strict 必须通过；
协议保持 p0.rgbwsv.2 / R G B W S V / uint8 / black_is_print。
```

## 3. 用户流程

```text
点击“导入模型”
-> 一次选择 1..N 个文件
-> 查看批量导入进度和逐文件结果
-> 在统一俯视图检查排版和纹理
-> 需要时调整模型/排版
-> 点击“切片当前场景”
-> 自动保存场景快照并执行场景预检
-> 显示切片、TIFF 保存、报告和总耗时
-> 自动加载输出 Package。
```

## 4. 批量导入规则

### 4.1 容量

```text
remaining = 22 - currentInstanceCount；
选择数 > remaining 时在导入前阻断，并提示可用名额；
不静默截断文件列表。
```

### 4.2 文件身份

```text
路径使用规范化绝对路径；
同一路径在不同批次导入时可创建新的 instance；
modelId 可按内容/资源身份复用；
instanceId 必须唯一且稳定可审计；
OBJ 的 MTL 和纹理仍从同级/相对资源路径解析。
```

### 4.3 失败处理

一个文件失败不回滚已经成功导入的文件，也不跳过后续文件。批次结束必须展示：

```text
选择数 / 成功数 / 失败数 / 取消数；
每个失败文件和稳定错误码；
是否执行自动排版；
当前场景实例数。
```

用户取消批次时，只取消尚未开始和当前协作请求，不删除此前已成功导入的实例。

## 5. 场景切片准入

P0 固定规则：

```text
只切 visible=true 的实例；
至少一个可见实例；
所有可见实例资源已加载且 transform evidence 未过期；
所有可见实例通过所选模式预检；
场景无碰撞、无越界；
使用同一 scene-wide Profile；
设备 buildVolume 未解析时不得冒充正式 production GO；
Advanced 测试幅面若启用，输出必须标记 productionReady=false；
Global 场景模式未准入时 fail-closed，不回退 Legacy。
```

## 6. 交互要求

```text
主按钮使用高视觉权重并靠近模型工作区；
按钮文字不与“运行切片”“导入模型并切片”并存造成歧义；
运行时按钮变为“停止切片”或提供紧邻取消按钮；
按钮下方只显示一条当前阻断/进度摘要；
详细日志进入底部诊断区；
批量导入使用一个进度摘要，不弹出 N 个模态窗口；
所有失败可从摘要进入详细列表。
```

## 7. 验收标准

```text
一次选择 3 个真实模型，可在同一场景显示并自动排版；
一次选择导致总数超过 22 时整体阻断且场景不变；
单个坏模型不删除同批次成功模型，并有明确汇总；
当前场景主按钮始终可见且状态可解释；
按钮不重新打开单模型文件对话框；
三实例场景经预检后产生一个 package 和每层一个 TIFF；
输出 scene identity 与当前不可变快照一致；
失败不生成伪成功 package，不跨模式静默回退；
成功后自动加载 TIFF 生产预览；
Debug/Release、UI Smoke、RIP strict 通过。
```

## 8. 非目标

```text
不做自动 nesting；
不做跨模型联合支撑；
不做 mixed-profile；
不做并行加载 22 个大模型；
不在本专项重排整个 MainWindow；
不把 OpenVDB 设为默认；
不改变生产 TIFF 协议。
```
