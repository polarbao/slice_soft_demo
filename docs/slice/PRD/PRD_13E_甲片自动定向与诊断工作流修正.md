# PRD 13E 甲片自动定向与诊断工作流修正

> 文档版本：v1.0
> 文档状态：APPROVED / READY
> 日期：2026-07-29

## 1. 背景

当前自动定向可以降低模型 Z 高度，但没有稳定处理几何评分相等的正反姿态。
同族甲片可能一个正面朝上、另一个正面朝下，最终表现为纹理、支撑和切片形态相反。

当前工作台又把可操作诊断与原始日志混合放在底部 Dock。用户在日常模型准备和预览过程中
难以及时看到朝向、越界、碰撞和材料问题。

## 2. 用户目标

```text
导入标准甲片后无需逐个判断正反面；
同批模型以一致的正面朝上姿态进入排版和切片；
默认允许实际高度不超过 9 mm 的甲片；
模型准备阶段在右侧直接看到诊断结论；
底部只在需要查看详细日志和报告时展开。
```

## 3. 功能需求

### 3.1 FR-13E-01 确定性自动定向

```text
所有启用 autoOrient 的 OBJ/STL/3MF 使用统一算法；
相同输入、配置和版本必须得到相同 selectedOrientation；
等价候选不得受亚纳米级浮点误差影响；
标准长轴甲片平放时优先正面朝 +Z。
```

### 3.2 FR-13E-02 高度默认值

```text
AutoOrientConfig 产品默认 maxHeightMm = 9.0；
Qt 一键导入/诊断/切片生成配置默认 maxHeightMm = 9.0；
普通用户可见生产 Profile 默认 maxHeightMm = 9.0；
Golden、负向和算法 fixture 可显式保留原值；
不得通过自动缩放满足高度。
```

### 3.3 FR-13E-03 诊断信息位置

右侧检查器提供“预检与诊断”入口，显示：

```text
准入状态；
模型方向与实际高度；
碰撞/越界；
材料与 Package 警告；
可执行的重新检查入口。
```

### 3.4 FR-13E-04 任务详情

底部 Dock 改名为“任务详情”，默认折叠。展开后可访问完整报告、材料闭环、
曲线、材料参数、工艺对比、切片耗时和日志。

## 4. 交互流程

```text
导入模型
-> 自动定向并记录结果
-> 右侧预检与诊断显示方向/高度/准入
-> 自动排版
-> 切片当前场景
-> 自动进入生产预览
-> 需要时展开底部任务详情
```

## 5. 错误与警告

| 情况 | 产品行为 |
|---|---|
| 等价姿态评分差在容差内 | 按稳定正向优先级选择，不提示错误 |
| 最优高度超过 9 mm | 保留尺寸并显示超高警告，不自动缩放 |
| autoOrient 被显式关闭 | 显示“使用源姿态”，不偷偷开启 |
| 模型语义正面无法判断 | 使用稳定几何策略，并允许后续人工变换 |
| 预检/报告存在阻断 | 右侧突出显示；详细证据可从任务详情查看 |

## 6. 验收标准

```text
MF_Mei_gui_wumingzhi_fx04.obj 不再选择 rotate_x_minus_90；
03.obj、04.obj、MF_Mei_gui_wumingzhi_fx04.obj 正面均朝场景 +Z；
三者的长轴 Y 方向一致；
默认 maxHeightMm 为 9.0；
右侧存在预检与诊断页且拥有 warningsDiagnosticView；
底部不再存在“诊断”页，窗口标题和菜单显示“任务详情”；
现有生产 TIFF 层序、通道和极性不变。
```

## 7. 非目标

不提供复杂自由旋转优化、AI 模型语义识别、自动缩放、模型修复或新 TIFF 协议。
