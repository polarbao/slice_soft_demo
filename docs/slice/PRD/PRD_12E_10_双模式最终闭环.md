# PRD 12E-10 双模式最终闭环

> 文档版本：v1.1
> 文档状态：FORMAL / 10A COMPLETE / 10B READY
> 日期：2026-08-03

## 1. 背景

12E 已完成全局纹理壳层、模型填充、双模式生产写包、Qt 产品入口和非等方 DPI，但阶段结果分散在
诊断、生产、协议、真实模型和性能报告中。12E-10 负责把这些证据收敛为一份单模型双引擎最终矩阵，
而不是增加第三种切片模式或修改生产协议。

## 2. 产品目标

```text
在同一真实 layerIndex/zMm 上检查生产 TIFF 与 Texture/Fill 诊断语义；
分别记录 Legacy 和 Global Surface Shell，不允许 silent fallback；
对正向真实模型执行 minimum/intermediate/allTexture 宽度矩阵；
对复杂拓扑模型保留 BLOCKED_EXPECTED，不伪造 package；
汇总 core、compose、TIFF、preview/report 和 peak memory；
形成用户手册、阶段报告和明确 GO/NO-GO 边界。
```

## 3. 用户验收

```text
生产 TIFF 可被 RIP strict 读取；
Texture Surface + Model Fill 在 model domain 内 overlap=0、unassigned=0；
同层 preview 与 report/mask 像素统计一致；
Legacy 保持默认；
Global 只在已准入 Profile 中显式选择；
失败模式无 fallback、无半成品、无假 PASS；
结果使用 slicesoft.stage12e.final_closure_matrix.1 汇总。
```

## 4. 范围

```text
10A：同层 preview 最终一致性；
10B：真实 OBJ/3MF 双模式宽度矩阵；
10C：Release core/compose/I/O/peak-memory 汇总与结论；
10D：用户手册、REPORT、索引和上下文封口。
```

## 5. 非目标

```text
不做多模型生产验收，Stage 13B 独立负责；
不关闭设备 buildVolume、机器轴或 22 实例预算；
不修复 aishen/meigui/titian confirmed self-intersection；
不把 OpenVDB 设为默认；
不实施冻结的 12G-TCWS；
不修改 p0.rgbwsv.2、RGBWSV、uint8 或 black_is_print；
不制定硬件打印质量 SLA。
```

## 6. 完成判定

12E-10A..D 全部完成，required 正向行 PASS，strict 阻断行 `BLOCKED_EXPECTED`，且最终报告明确：

```text
Legacy 默认生产状态；
Global 显式候选状态；
性能/内存差异；
复杂模型覆盖缺口；
外部设备输入；
后续 12F 性能或 Stage 13 中长期路线。
```
