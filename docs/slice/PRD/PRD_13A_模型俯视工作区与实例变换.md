# PRD_13A 模型俯视工作区与实例变换

> 文档版本：v0.1
> 文档状态：Formal PRD / PREPARED
> 生成日期：2026-07-24

## 1. 背景

当前 Qt 软件在切片前不能直观看到模型姿态、占地范围和 XY 位置，也不能在界面中选择模型后完成
移动、旋转、缩放或镜像。用户只能导入模型并立即进入现有自动姿态和切片流程。

## 2. 产品目标

### 2.1 短期

提供可用于生产准备的俯视工作区：

```text
从 +Z 查看 XY 平面；
显示毫米网格、X/Y 轴、全部可见模型、纹理、包围盒和选择状态；
支持模型选择；
支持 translateX/translateY；
支持 rotateZ；
支持 uniformScale；
支持 mirrorX/mirrorY；
模型 Z 落台和自动姿态继续沿用当前项目逻辑。
```

### 2.2 中期

提供真实 3D 模型查看：

```text
透视/正交相机；
轨道旋转、平移、缩放；
实体、线框、包围盒和纹理显示；
模型拾取；
顶/前/侧/等轴测标准视图；
模型高度、尺寸和坐标摘要。
```

### 2.3 长期

提供 3D 打印软件常见场景交互：

```text
三轴移动/旋转/缩放 gizmo；
镜像、复制、删除、隐藏、锁定；
对齐、吸附、居中、落台；
撤销/重做；
多选和批量变换；
自动朝向和高级排版入口。
```

## 3. 用户故事

### US-13A-01 切片前检查

作为打印操作人员，我希望导入模型后先看到俯视图、尺寸和坐标，以确认模型没有明显放反或超出范围。

### US-13A-02 选择和变换

作为打印操作人员，我希望选中一个模型后输入或调整 X/Y、旋转角度和缩放比例，并立即看到俯视图更新。

### US-13A-03 镜像

作为打印操作人员，我希望对选中模型执行 X 或 Y 镜像，并在切片前看到镜像结果和几何准入状态。

### US-13A-04 重置

作为打印操作人员，我希望一键恢复导入后的默认姿态和位置，避免手工逐项还原。

## 4. 短期交互

主工作区提供：

```text
模型画布；
模型列表或当前选择摘要；
X(mm)、Y(mm)；
绕 Z 旋转(度)；
统一缩放(%)；
镜像 X、镜像 Y；
居中、重置、适应视图；
尺寸 W/H/Z 和准入状态。
```

画布支持点击选择。短期可使用数值控件完成精确变换；XY 鼠标拖动可以作为同阶段增强，但不得以
鼠标拖动替代数值输入。Z 数值控件不显示或保持只读。

## 5. 业务规则

```text
所有距离单位为 mm；
translateX/translateY 步长 0.01 mm；
rotateZ 步长 0.1 度；
uniformScale 默认 100%，不得为 0 或负数；
短期不允许非均匀缩放；
短期不允许 rotateX/rotateY；
镜像后必须重新执行 transformed geometry preflight；
变换后模型 minZ 由当前落台策略重新确定；
被阻断模型不能通过 UI 强制进入生产切片。
```

## 6. 状态与错误

UI 必须区分：

```text
未加载；
正在导入；
可编辑；
分析中；
准入通过；
警告；
阻断；
变换后结果过期；
资源缺失。
```

错误提示必须包含 `modelId/instanceId`、问题类型和建议动作，不只显示“操作失败”。

## 7. 非目标

```text
不在短期实现自动 nesting；
不在短期实现支撑手工编辑；
不修改模型源文件；
不让显示模块决定材料策略；
不绕过现有自动姿态和 ProductionAdmissionPolicy；
不要求 OpenVDB 才能显示模型；
不在短期锁定 VTK 或 Qt3D。
```

## 8. 验收标准

```text
导入 OBJ/STL/3MF 后俯视图可见且不为空；
同一场景的全部 visible 实例在统一 +Z 俯视坐标系中可见；
追加导入默认按当前规则排版，避免同原点重叠造成“只显示一个模型”；
有效 UV/贴图显示贴图颜色，无贴图时显示材质 diffuse 或稳定回退色；
俯视包围盒尺寸与核心模型摘要一致；
X/Y 移动后画布和最终 effective config 一致；
rotateZ、uniformScale、mirrorX/mirrorY 均可保存、回读和重置；
Z 落台结果与未引入 13A 前的当前生产逻辑一致；
切换选择不会把变换写到其他实例；
变换导致准入失败时，切片按钮被阻断并显示原因；
1280x720、1440x900、1920x1080 不遮挡；
Qt self-test 和 UI smoke 覆盖最长中文和错误状态。
```

## 9. 成功指标

```text
单模型从导入到确认位置不需要手工编辑 JSON；
用户可以在切片前识别模型方向、占地和越界；
变换参数可审计并进入 session effective config；
显示操作不改变 p0.rgbwsv.2 输出协议。
```
