# PRD 13D Qt 工作台信息架构与布局收口

> 文档版本：v1.1
> 文档状态：COMPLETE / 13D-01..04 PASS
> 日期：2026-07-29
> 前置：13B-08 COMPLETE、13C-05 COMPLETE

## 1. 背景

当前工作台已经逐步增加模型列表、变换、排版、参数、预检、诊断、工艺对比和多种旧切片入口，功能
可以单独使用，但信息层级仍是调试工具形态：

```text
主切片动作埋在左侧长按钮列表；
中央画布右侧同时存在两个常驻侧栏；
模型编辑和模型预检被拆开；
诊断/工艺对比与底部 DiagnosticsDock 职责重复；
仓库路径、可执行文件和高级入口长期占据首屏；
窄窗口下中央画布被明显压缩。
```
## 2. 目标

将 Qt UI 收敛为以“准备模型 -> 切片 -> 检查结果”为主线的工作台，不删除现有能力：

```text
顶部：作业级主动作；
中央：模型、生产预览、配置三个主工作区；
右侧：单一上下文检查器；
底部：可折叠诊断与日志；
左侧：可折叠项目/输出/高级工具，不再承载主切片动作。
```

## 3. 信息架构

### 3.1 顶部作业栏

固定包含：

```text
导入模型；
保存场景；
切片模式/Profile 摘要；
切片当前场景；
取消；
当前状态。
```

主切片按钮在任何主页面都可见。不可执行时禁用但不隐藏，并提供具体原因。

### 3.2 中央工作区

一级页只保留：

```text
模型；
预览；
配置。
```

`预览` 内部由 13C 负责生产 TIFF 与诊断预览，不在 13D 重新发明数据源。

### 3.3 上下文检查器

把截图中的两个右侧区域重组为一个可切换、可折叠检查器：

| 上下文页 | 内容 |
|---|---|
| 场景 | 模型列表、显示/锁定、场景摘要 |
| 变换 | X/Y、rotateZ、缩放、镜像、重置 |
| 排版 | 11x2、行列间距、自动排版 |
| 切片设置 | 当前 Profile 的常用参数摘要和跳转 |
| 预检 | 当前实例/场景准入结果和阻断原因 |

检查器默认宽度应稳定，不因标签文字切换造成画布抖动；允许用户折叠并记忆状态。

### 3.4 底部诊断区

统一承载：

```text
报告；
材料闭环；
曲线；
工艺对比；
日志。
```

主流程仅显示一行摘要，详细内容在底部展开。最右侧不再保留第二套“诊断/工艺对比”常驻页。

### 3.5 项目与高级工具

仓库根目录、CLI 路径、RIP 检查器路径、旧单模型兼容入口、快速回归和输出路径等移入可折叠的
“项目与高级工具”。默认收起；路径必须可复制，但不再挤占模型画布。

## 4. 交互要求

```text
导入多个模型后焦点回到画布，检查器切到“场景”；
选择模型后自动切到上次使用的“变换”或保持用户选择；
碰撞/越界时检查器“预检”显示警示标记，但不抢夺键盘焦点；
切片开始后顶部主动作显示运行状态，底部日志按需展开；
切片成功后自动进入“预览”，保持当前 Package；
用户折叠的左/右/下区域在下次启动恢复；
不得通过隐藏错误或自动 fallback 简化界面。
```

## 5. 响应式布局

最低验证视口：

```text
1280 x 720；
1440 x 900；
1920 x 1080；
150% Windows DPI 缩放下的 1440 x 900 逻辑视口。
```

规则：

```text
中央画布始终保留可工作的最小宽度；
不足时先折叠项目区，再折叠上下文检查器，不压扁主动作；
中文按钮允许自然换行或合理最小宽度，不截断关键动作；
垂直滚动只出现在具体检查页，不让整个窗口同时出现多条滚动条；
切换标签不得改变工具栏高度或引起画布跳动。
```

## 6. 验收标准

```text
顶部可直接完成导入、保存和切片当前场景；
同一时间最多一个右侧检查器常驻；
模型列表/变换/排版/预检均可从检查器到达；
报告/材料闭环/曲线/工艺对比/日志均可从底部 Dock 到达；
左侧项目区和右侧检查器均可折叠并恢复；
1280x720 和 150% 缩放下无关键控件遮挡；
旧能力没有被删除或藏到不可发现位置；
现有 UI self-test、13B-08 和 13C Smoke 不回归。
```

## 7. 非目标

```text
不引入新的 3D 渲染库；
不重写 scene/pipeline/core；
不改变 TIFF/Package/RIP；
不在本阶段做自动 nesting；
不删除旧兼容能力，只调整入口层级；
不在 13C 完成前提前合并预览数据源。
```
