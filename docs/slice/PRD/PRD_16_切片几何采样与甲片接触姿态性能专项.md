# PRD_16 切片几何采样与甲片接触姿态性能专项

> 阶段：Stage 16
> 状态：PROPOSED / NOT ACTIVE
> 版本：v0.1
> 日期：2026-08-06
> 决策依据：`DOC_DECISION_16_切片几何采样甲片接触姿态与性能专项.md`

## 1. 问题陈述

当前生产切片通过层中心和 XY 像素中心点决定几何占据。对具有渐尖、弧形、斜边或残余侧倾的甲片，该策略会让首层出现过少或断续像素。

2026-08-06 对 `segment_101` 的只读对比显示：

```text
SliceSoft 首层模型像素：16；
参考切片器首层模型像素：71；
SliceSoft 模型总像素：4,800,409；
参考切片器模型总像素：5,092,513；
两者非空模型层都为 332，不是缺层；
SliceSoft 额外写出一个尾部空层。
```

另一方面，现有确定性自动定向已保证正反面和尖端朝向，但不做连续小角度接触调平。采样和姿态任一变化都可能增加计算量，因此必须与 12F/13F 未完性能治理合并评估。

## 2. 产品目标

```text
1. 薄边和小特征不因半层相位或单中心点采样无意消失；
2. 采样策略有明确物理语义、版本化配置和可回退基线；
3. 甲片接触姿态能被量化诊断，而不是靠截图或单顶点判断；
4. 可选调平不破坏正面 +Z、尖端 +Y、尺寸和准入合同；
5. 新策略对单模型和 22 实例场景的时间/内存影响可测量；
6. 在 Stage 14 完成前不开始实施，完成后仍需 GO/DEFER/NO-GO 复核。
```

## 3. 非目标

```text
不修改 RGBWSV 协议、通道、位深和极性；
不重新打开 OpenVDB 默认切片器替代；
不在基础占据中隐式加入打印补偿/膨胀；
不强制所有模型两个最低顶点同时着地；
不为单一 Reality 文件族写特判；
不把参考 TIFF 当作未经确认的唯一产品真源；
不在设备 SLA 缺失时宣布 22 实例 production GO。
```

## 4. 功能需求

### FR-16-01 采样策略可配置

系统至少保留：

```text
legacy_center_sample；
layer_slab_supersample_candidate。
```

未声明配置必须继续使用 Legacy 语义，不允许静默切换。

### FR-16-02 层体积占据

候选策略对第 `i` 层使用半开体积区间：

```text
[i * layerThicknessMm, (i + 1) * layerThicknessMm)
```

精确边界和浮点容差必须是配置无关的稳定合同。

### FR-16-03 XY 覆盖率采样

首个候选必须支持边界 2x2 超采样，并对 `>=2/4` 和 `>=1/4` 分别产出证据。内部确定像素可使用快速路径，不要求全格 4 倍无条件采样。

### FR-16-04 姿态诊断

对候选甲片输出：

```text
当前定向及旋转角；
左/右边界带下包络差；
前 1 层和前 2 层接触面积；
受限长轴调平候选角；
高度、占地、方向和准入约束是否满足；
候选被拒绝或回退的原因。
```

### FR-16-05 姿态实施边界

首版姿态改善必须先是 diagnostic-only。获得独立授权后，只允许在甲片长轴约束下小角度调平，并保留人工关闭。

### FR-16-06 可观测性

性能报告至少包含：

```text
modelId/sceneId/strategyId/grid/layerCount；
modelLoad/maskSampling/supportGeneration/layerCompose/write/preview/report；
cold/warm cache；
producer/reuse count；
peak working set 和显式预算；
candidate vs legacy 逐层/通道差异总结。
```

### FR-16-07 性能治理

在不改变已选采样语义的前提下，依次评估：

```text
支撑统计扫描融合；
bottom projection range/provider；
layer compose 扫描融合和 buffer 复用；
occupancy provider 与分块/流式生成；
几何、支撑和平移重复实例缓存；
preview/I/O 解耦；
有内存上限的有限并行。
```

## 5. 非功能需求

| ID | 需求 |
|---|---|
| NFR-16-01 | Legacy 默认下既有 golden/package 字节不漂移 |
| NFR-16-02 | 候选结果确定，不随线程数、执行顺序或场景实例顺序变化 |
| NFR-16-03 | 2x2 候选的性能回归必须用 Release core-only 和 end-to-end 两个口径分别报告 |
| NFR-16-04 | 超采样不允许通过无界内存或无界并行换取速度 |
| NFR-16-05 | 新策略不改变 Stage 15 补白和材料闭合语义 |
| NFR-16-06 | 姿态候选不得在 UI 线程执行高成本网格搜索 |
| NFR-16-07 | Stage 14 Facade/SPI/Worker 若需扩展，必须版本化且不修改已冻结 v1 语义 |

## 8. 待确认产品问题

```text
Q1 几何边界优先尺寸忠实还是“任意命中不丢特征”；
Q2 一个像素正偏差的允许范围；
Q3 外部切片器 TIFF 的通道和分层权威语义；
Q4 两侧接触是观感期望，还是有定量打印失败数据；
Q5 连续调平允许的最大角度；
Q6 22 实例的目标设备、SLA、内存上限和是否包含 TIFF/RIP；
Q7 Stage 16 策略是否需要暴露为 Stage 14 公开 SPI 能力。
```
