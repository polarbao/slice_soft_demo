## 1. 版本结论

- `RIPDLL_20260917` 修复 Windows 中文路径的宽字符模块定位和 DLL 加载。
- `RIPDLL_20260918` 的 CLI 源码与 0917 一致，但 EXE/DLL 重新生成，DLL 二进制发生变化。
- `RIPDLL_20260920` 新增 `-v/--verbose`，默认过滤 `RIP_LOG_DEBUG`，且 DLL 再次变化。
- 三版 `rip_slicer.h` 逐字节一致，现有进程外 CLI 集成不需要修改公开 ABI。
- 三个新目录均缺 `CmykFiles`。最终模块显式组合 0920 二进制与 0909 完整资源，0917/0918 只作为中间版本证据。

## 2. 实施内容

- `rip_module/source.json` 升级为 `slicesoft.rip.source.2`，分别固定 `binaryDirectory` 和 `resourceDirectory`。
- 解析器兼容 v1/v2，对非法 schema、路径逃逸、缺二进制和缺资源 fail-closed。
- 打包器分别复制 3 个二进制和 8 个资源；`source_provenance.json` v2 记录双来源。
- RIP 模块版本提升为 1.3.0；CMake、Runtime 部署、宿主准入和合同 fixture 同步更新。
- 模块自检要求 `--transparent <0-4>`、`--ripmode <0|1>` 与 `--verbose`；生产命令不注入 `--verbose`。
