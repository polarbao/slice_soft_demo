## 4. 决策

16C-02 完成的是可重复的工程基线，不是 SLA 认证。设备 buildVolume/origin/axes、22 实例目标时限和
内存上限仍未由产品/设备侧冻结，因此 `productionStatus` 必须保持 `INPUT_OPEN`。S0 继续是生产默认，
S3 只可进入 16D-01 显式 opt-in，S4 保持薄特征上限对照。
