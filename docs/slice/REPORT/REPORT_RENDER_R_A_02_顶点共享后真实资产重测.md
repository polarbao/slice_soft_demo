# REPORT R-A-02 顶点共享后真实资产重测

> 状态：**COMPLETE / RD-B TRIGGERED**
> 日期：2026-08-10
> 配置：Release，宿主默认 `maxBytes=128 MiB`

## 1. 结论

- 36 个冻结 OBJ 均进入复测：**22 个单实例以 lod0 完整显示，0 个预算拒绝，14 个按既有纹理资产合同显式拒绝**；
- R-B-05 后 22 个可显示资产平均仍为 **105.15 B/三角**，相对 108 B 仅下降 **2.64%**；
- 原因是当前 `SceneModel` 不保存输入顶点法向，Builder 使用面法向；曲面相邻三角法向不同，
  `position + normal + uv` 安全键不能共享这些顶点；
- 22 个可显示资产聚合后实际返回 **lod2**，不是 lod0。当前破坏性跳采样仍会在真实多模型场景触发；
- 因此 RD-B 的启动条件成立，但第三方依赖仍须单独获得明确授权后才能引入。

## 3. 聚合场景证据

22 个可显示资产的逐实例 lod0 统计合计：

| 项目 | 字节 | MiB |
|---|---:|---:|
| Mesh | 108320904 | 103.30 |
| Texture | 109574672 | 104.50 |
| 两者合计（尚未计固定开销） | 217895576 | 207.80 |

实际聚合请求经过 identity 去重与预算候选选择后返回：

```text
sceneInstances=22
lod=lod2
triangles=157405
meshBytes=16979900 (16.19 MiB)
textureBytes=105380368 (100.50 MiB)
```

这不是预算拒绝，但属于几何质量降级。按 22 个独立模型和实测平均 105.15 B/三角解释：

- 不计纹理时，128 MiB 对应约 **58021 三角/模型**；
- 保留当前逐资产纹理总量时，仅剩约 **10653 三角/模型**的理论 mesh 预算；
- 实际阈值还受 identity 去重、固定开销和每个模型面数分布影响，不能再使用 R-A-01 的单一 13.8k 口径。
