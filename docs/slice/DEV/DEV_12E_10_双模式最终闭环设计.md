# DEV 12E-10 双模式最终闭环设计

> 文档版本：v1.1
> 文档状态：FORMAL / 10A-10B COMPLETE / 10C READY
> 日期：2026-08-03

## 1. 架构原则

```text
不新增生产 writer；
不新增 package schema；
只编排现有 Legacy/Global、09B、09C、09A 和 13C 能力；
最终矩阵是验证产物，不是生产输入；
Qt 只负责触发和查看，不计算核心分区；
每条结果必须保留 pipelineMode、Profile、identity 和 no-fallback 证据。
```

## 2. 数据流

```text
固定 case + width point
  -> 生产 Effective Config
  -> Legacy 或 Global 显式 route
  -> RGBWSV package + manifest/report
  -> RIP strict
  -> TiffLayerSource / MaterialPreviewComposer
  -> 09A 同层 diagnostic evidence
  -> FinalClosureMatrix case
```

生产失败时：

```text
preflight/admission error
  -> blockingCodes
  -> productionOutputWritten=false
  -> result=BLOCKED_EXPECTED 或 FAIL
```

不得切换到另一引擎补结果。

## 3. 矩阵实现

复用 `DOC_SCHEMA_12E_FinalClosureMatrix.md`，建议增加独立 runner：

```text
scripts/run_12e_10_final_closure.ps1
```

runner 职责：

```text
检查 Release runtime、fixture 和模型资产；
为每个 case 生成隔离输出目录；
执行显式 pipeline/Profile；
调用 RIP Reader strict；
收集 report/manifest/timing/memory；
校验 package identity 和 TIFF layer list；
写 final_closure_matrix.json；
失败时保留日志和稳定 result，不覆盖旧成功证据。
```

## 4. 固定 case

```text
正向 OBJ：xiao_ma baseline family；
正向 OBJ：yecan baseline family；
格式控制 3MF：texture2d_checker_cube.3mf；
阻断披露：aishen_fudiao、meigui_fudiao、titian_fudiao。
```

正向模型每个引擎使用：

```text
minimum；
representative intermediate；
all_texture。
```

不适用的组合必须写 `NOT_EVALUATED` 及原因，不能删除行。

## 5. Preview 对齐

10A 只消费已经完成的：

```text
13C TiffLayerSource；
13C MaterialPreviewComposer；
09A-05 DiagnosticSemanticPreview；
09C dpiX/dpiY 和物理像素；
09B production session/package identity。
```

检查：

```text
layerIndex 精确相同；
zMm 在约定容差内一致；
raster width/height 相同；
Texture/Fill count 与 diagnostic mask 一致；
W/S/V 与生产 TIFF 探针一致；
物理宽高比使用 dpiX/dpiY；
不生成第二套生产预览文件。
```

10A 实现补充：生产 package 的 `p0.material_closure.1` 精确报告作为第三类只读证据参与绑定。
`layerIndex/zMm` 不一致、报告缺失或仅为 candidate 时 fail-closed；闭环失败层仍允许查看，但必须显示
`FAIL/gapPixels`，不得提升为 PASS。

## 6. 性能口径

```text
coreMs：几何/分区核心；
composeMs：材料与场景/图层合成；
tiffSaveMs：生产 TIFF 写入；
previewReportSaveMs：诊断图和报告写入；
totalMs：进程或 runner 总耗时；
peakWorkingSetBytes：同一参考机进程峰值。
```

比较引擎时以 `coreMs` 和 `peakWorkingSetBytes` 为主，同时披露完整总耗时。不得把关闭预览写出的
结果与开启诊断图写出的结果直接作为引擎速度结论。

## 7. 文件所有权

```text
scripts/run_12e_10_final_closure.ps1
tests/fixtures 或 samples/configs 下的只读矩阵输入
tests/golden/expected 下的 schema/golden
docs/slice/REPORT/REPORT_12E_全局纹理壳层与模型填充当前状态.md
docs/user_guides 下的阶段用户说明
```

除非验证暴露真实缺陷，10B/10C 不应修改核心切片算法。

## 8. 回滚

```text
runner 和矩阵失败不影响现有生产入口；
所有输出写入隔离 benchmark/session 目录；
不覆盖 samples/configs；
不修改 Legacy 默认 Profile；
任何新 summary 消费者可独立移除，不影响 package/RIP。
```
