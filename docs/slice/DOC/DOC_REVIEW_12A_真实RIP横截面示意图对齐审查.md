## 3. 对前一版概念图的判断

前一版 `DIAGRAM_12A_内部镂空支撑与外侧光油支撑关系.svg` 存在以下问题：

```text
1. 它把指甲横截面画成单个蓝色实心模型体，不符合真实 RIP 中“支撑大面积承托 + 模型材料带状分布”的视觉结构。
2. 它把内部镂空画成一个独立椭圆洞，容易误导实现为单个孤岛填充；真实 RIP 更像按模型内外轮廓之间的区域生成连续材料带和支撑区域。
3. 它没有表达外表面光油、内表面光油、外/内表面色彩层、模型内部填充层的层叠关系。
4. 它把上表面支撑画成画布顶部的帽状区域，容易误解为 2D 图像坐标的“上方”；真实语义应是沿模型表面法向/材料栈外侧的可剥离支撑。
5. 它仍可作为“优先级概念图”参考，但不能作为 12A 几何形态或材料带验收图。
```

结论：

```text
12A 后续文档应以 DIAGRAM_12A_指甲模型横截面材料示意图.png 作为主要横截面材料栈参考。
旧图应降级为概念图，不再作为 PRD/DEV/DEMO 的主要验收示意。
```

## 4. 修正后的材料栈

根据用户示意图和 `slice.446.png`，12A 需要表达以下横截面材料栈：

```text
从模型外侧/上表面向内：
1. 上表面支撑 S
2. 表面层光油 V / VeroClear
3. 模型表层色彩层 RGB
4. 模型内部填充层，默认白墨 W / VeroPureWht
5. 模型表层色彩层 RGB
6. 模型内表面光油层 V / VeroClear
7. 模型下表面支撑层 S
```

关键语义：

```text
1. 支撑区域不只存在于模型下方，也可围绕模型外部或内部区域形成可剥离承托。
2. 光油层不应只理解为“外侧壳层”，真实工艺还需要内表面/表面清漆层。
3. 色彩层可能在外表面和内表面各出现一次。
4. 模型内部填充层位于两侧色彩层之间，默认白墨，生产 Profile 不允许为空。
5. 内部镂空支撑应按模型内外轮廓围成的可支撑区域处理，而不是一个固定椭圆。
```
