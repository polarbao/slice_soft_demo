# DOC_SPEC_MATERIAL_NAMING 多图层素材命名与语义标识规范

> 文档状态：**ACTIVE / 首版（用户 2026-09-01 裁定）**
> 版本：v1.0 ｜ 日期：2026-09-01
> 定位：**设计侧与切片侧共用的素材命名契约**。本规范是「素材名 → 材料语义 + 图层序」
> 的唯一权威定义，供设计侧导出与切片侧识别双方遵循。
> 关联：`DOC_DECISION_MATOPQ_材质不透明度识别与光油通道映射专项.md`
> `DOC_DECISION_MATVOL_T_RGBWSVT协议与缩裹材料通道.md` §3.0（T 通道术语）

---

## 1. 命名格式

```text
<素材名>-L<图层号>

图层号   从【最上层】起为 1，依次向下递增：L1、L2、L3 …
分隔符   半角连字符 `-`，前后不留空格
```

示例（两图层，每层一个透明素材 + 一个不透明素材）：

```text
trans-L1     图层 1（最上层）的透明素材
sg-L1        图层 1 的不透明素材
trans-L2     图层 2 的透明素材
sg-L2        图层 2 的不透明素材
```

## 1.1 L<n> 是【设计语义】，不是物理 Z 位置（用户 2026-09-01 补充）

```text
设计侧固定语义   L1 永远是设计上的最上层，L2 在其下，依次递增。
                 该编号【由设计意图决定】，与模型在切片软件中的朝向无关。

切片侧可能反转   autoOrient 会对模型做右角度旋转/翻转以压低高度，
                 反转后【物理上 L2 可能位于 L1 之上】。
                 这不构成矛盾，也不需要重新编号。
```

**为何反转不影响 priority（实现依据，勿改）：**

```text
priority 只在【材质体积重叠时】参与裁决，回答的是
「设计意图上谁应当覆盖谁」，不是「谁的 Z 更高」。

两个材质体积是否重叠属几何事实，模型反转后它们【仍然重叠】，
重叠关系不随朝向改变；而设计意图同样不随朝向改变。
故 L1 优先级最高应读作「L1 是设计上的表面层，重叠时覆盖下层」，
【不得】读作「L1 在 Z 轴上更高」。

推论   ResolveMaterialLayerNaming 只看材质名，不看几何、不看朝向，
       这是刻意的：一旦让它感知 Z，autoOrient 就会改变材质归属，
       同一份资产在不同摆放下会切出不同产物。
```

## 2. 素材名词表

| 材料 | 标准名 | 简写 | 落入通道 | 识别依据 |
|---|---|---|---|---|
| 透明素材（不透明度 100% 透明） | `transparent` | `trans` | **V**（光油） | **MTL 的 `d` 值**（主判据）+ 名称（交叉校验） |
| 缩裹材料 / 弹性材料 | `elasticity` | `el` | **T** | 名称（拟改）/ 当前为 `Kd` 匹配 |
| 其他常规素材 | 不约束 | — | RGB | — |

```text
标准名与简写【等价】，切片侧对两者同等处理。
大小写不敏感（切片侧做小写归一后匹配）。
```

## 3. 与既有术语的对应

```text
弹性材料 = 缩裹材料 = transfer = T 通道 = elasticity / el
  （权威定义见 DOC_DECISION_MATVOL_T §3.0，通道字母 T 取自「弹性」拼音首字母）
透明素材 = 光油 = V 通道 = transparent / trans
  （光油判据见 DOC_DECISION_MATOPQ §7 C1：d <= opacityMax）
```

## 4. 对切片侧的作用（逐项说明能解决什么）

### 4.1 能解决：素材可区分

```text
问题   多图层的同类素材此前无法区分。
       tm3 的两层不透明素材同名为 sg (3) / sg (2)，且旧解析器把两者截断为同一个 sg；
       tm2/tm3 的两层透明素材【共用同一个 touming】，连名字都相同。
解决   -L<n> 后缀使每个素材在全模型内唯一。
依赖   MO-06 已修的整行取名（材质名不再被空格截断），已随本专项落地。
```

### 4.2 能解决：`overlap.rules` 的优先级可自动生成

```text
问题   MATVOL 要求逐材质【显式声明】priority，同级 fail-closed、缺声明 fail-closed。
       4 素材需要 4 条规则，靠人工填写不可持续。
阻碍   此前无法按名推导层序——tm2-3 的 touming-2 位于【上层】、touming-1 位于【下层】，
       编号与层序【反向】，任何按名字数字推层序的逻辑都会推反。
解决   -L<n> 规范把层序写进名字且方向确定（L1 = 最上层），可可靠推导。

自动生成公式（已实施，MaterialLayerNameResolver）
  层步长     (最大层号 + 1 - 本层号) * 100     ← 层序【主导】
  类别次序   弹性 el 30 ｜ 常规 20 ｜ 透明 trans 10   ← 仅在同层内区分
  priority   层步长 + 类别次序

两图层示例
  nail-L1    (2+1-1)*100 + 20 = 220
  trans-L1   (2+1-1)*100 + 10 = 210
  nail-L2    (2+1-2)*100 + 20 = 120
  trans-L2   (2+1-2)*100 + 10 = 110

为何层序必须主导（实测教训，2026-09-01）
  首版公式把【类别】设为主导（类别间隔 100、层序间隔 10），
  两图层时 nail-L2(210) 反而压过 trans-L1(120)，
  实测导致 1993 个像素本应归光油却落入 RGB。
  L1 是设计上的表面层，其光油必须覆盖 L2 的彩色——
  故层步长必须远大于类别间隔。该错误由端到端对照实测发现，
  单测只验证「公式算得对」，验不出「公式设计得对」。

约束   priority 必须全局唯一；同层同类重名会撞号，由解析器回报 collision。
```

### 4.3 能解决（新增可能）：缩裹材料的多图层匹配

```text
问题   transfer 当前按 Kd 匹配（matchSource 硬锁 material_diffuse_rgb），
       且要求【恰好命中 1 个材质】（multipleMatches 只允许 fail_closed）。
       多图层各有一份缩裹素材时必然命中 2 个 -> E_MATVOL_T_MATCH_AMBIGUOUS，
       且【同色异色都一样会撞】，改颜色无效。
解决   若把 transfer 的 matchSource 扩展为支持【按名匹配 el】，
       则 el-L1 与 el-L2 可各自独立识别，冲突消失。
归属   该改动在 MATVOL-T 专项范围（ResolveTransferMaterial / TransferChannelConfig），
       需单独授权，不属 MATOPQ。
状态   提案，未实施。
```

### 4.4 **不能**解决：多图层贴图/纵深表达

```text
问题   relief_heightfield 模式逐【XY 列】取顶面材质（slicer.cpp:2528），
       每列只有一个 top_triangle_index，结构上表达不了同列纵深叠放。
       实测表现为「下层贴图不出现」。
与命名的关系   【无关】。这是切片路径的结构限制，改名不能解决。
解决途径   必须启用 materialVolumePolicy（MATVOL）的 closed_intervals 真三维区间求解，
           并配 geometrySampling.degenerateAreaEpsilonMm2 = 1e-24
           （否则 CAD 导出的 nm^2 级合法薄面被误杀，MATVOL 判开放表面直接拒绝）。
```

### 4.5 对透明→光油识别是**冗余但有价值**

```text
现状   MO-04 的光油判据用 MTL 的 d 值（d <= opacityMax），【不依赖名称】。
       故 trans 命名对该识别不是必需的。
价值   仍建议遵循，理由两条：
       1. 交叉校验——名为 trans 而 d != 0，或 d == 0 而名不含 trans，
          都提示资产制作有误，可作为预检告警项；
       2. 人工可读——报告与 UI 中材质名自解释，排查成本显著降低。
```

## 5. 已确认口径（用户 2026-09-01 回签）

```text
A1  常规素材的【名字主体】不约束，但 -L<n> 后缀【必须带】。
    即「素材1-L1」中 `素材1` 可自由命名，`-L1` 是强制后缀。
    否则无法推导层序，§4.2 的自动 priority 生成失效。

A2  单图层模型【也必须带 -L1】。
    使解析逻辑无需区分单层与多层两套分支，降低分歧面。
```

**由此得到的强制规则（设计侧必须遵守）：**

```text
R1  每个 usemtl 材质名都必须以 -L<n> 结尾，n 为正整数，L1 = 最上层。
R2  透明素材的名字主体必须为 transparent 或 trans。
R3  缩裹/弹性材料的名字主体必须为 elasticity 或 el。
R4  常规素材名字主体自由，但不得与 R2/R3 的保留词冲突。
R5  同一模型内材质名必须唯一（由 -L<n> 天然保证同类不重名）。
R6  【同一图层内的所有素材必须使用同一个层号】。
    即上层写 nail-L1 + trans-L1，下层写 nail-L2 + trans-L2；
    不得出现同层素材层号不一致（如 nail-L1 与 trans-L2 实为同层）。
```

**R6 的来由（实测暴露，2026-09-01）：**

```text
tm2-4 的四个材质为 nail-1 / trans-2 / trans-1 / nail-2：
  nail 的编号为 1,2（顺序），trans 的编号为 2,1（倒序）。
由此产生两种互不相容的层序读法：
  解读A（数字即层号）  L1={nail-1, trans-1}  L2={trans-2, nail-2}
  解读B（段序成对）    L1={nail-1, trans-2}  L2={trans-1, nail-2}
实测两种解读【产物不同】：V 相差 321 像素（占模型 0.012%），
两者守恒均成立、都是合法产物，仅那 321 像素归光油或归彩色不同。
用户 2026-09-01 裁定采用【解读 A】。
R6 的作用是让此类歧义在源头不再出现——命名本身即自解释，无需任何人推断。
```
