# DOC_DECISION_16 切片几何采样、甲片接触姿态与性能专项

> 阶段：Stage 16
> 文档状态：PROPOSED / DOCUMENTATION READY / IMPLEMENTATION DEFERRED
> 日期：2026-08-06
> 启动约束：Stage 14 收口前不得进入代码实施；Stage 14 收口后必须先执行 16-00 GO/DEFER/NO-GO 复核
> 上游证据：12B-R1、12F、12E-10C、13B-07、13E、13F、13G、Stage 15 及 2026-08-06 `segment_101` 双切片器对比

## 1. 决策结论

建立 Stage 16 专项，但当前只做文档、基线和准入准备，不抢占 Stage 14 实施主线。

本专项统一处理三条相互制约的问题线：

```text
A. 切片几何采样：中心平面采样会丢失首层薄边和亚像素特征；
B. 甲片接触姿态：现有直角定向不执行连续小角度接触调平；
C. 性能收口：新采样会增加计算量，必须与 12F/13F 未完性能任务同一预算治理。
```

顺序冻结为：

```text
先冻结可观测基线
-> 再做采样候选
-> 再做姿态诊断/候选
-> 然后执行性能治理
-> 最后才评审生产默认值
```

## 2. 当前状态

### 2.1 采样当前态

现有 `relief_heightfield` 路径已经使用 XY 列的 `z_min/z_max` 和列层范围，但几何占据仍由：

```text
Z：(layerIndex + 0.5) * layerThicknessMm 层中心
XY：单一像素中心点
```

决定。该语义是既有生产基线，不得静默替换。

### 2.2 姿态当前态

13E/13G 已冻结标准甲片的正面和俯视朝向。Reality 模型当前选择：

```text
rotate_x_180_rotate_z_minus_90
```

现有自动定向只组合确定性直角旋转、正反面和平面朝向归一，不进行任意小角度找平。

### 2.3 性能当前态

```text
12B-R1：COMPLETE，证明 supportGeneration 和 layerCompose 是主要热点；
12F-R0/R0-R1：COMPLETE，Release Runtime 和增量构建轨道已完成；
12F-02..09：NOT ACTIVE，仍待执行；
13F-R0 与 R1-06：COMPLETE；
13F-R1-01..05：READY/PENDING；
13B production GO：仍等待 22 实例正式性能预算等外部输入。
```

12B-R1 的历史 Release 证据中，`maskSamplingMs` 仅占核心计算约 1.50%..2.27%，但 Stage 16 的超采样会改变该比例，不得直接沿用历史热点排序。

## 3. 采样候选方案

| 编号 | 方案 | 优点 | 主要风险 | 定位 |
|---|---|---|---|---|
| S0 | 层中心 + XY 中心点 | 现有结果稳定，性能好 | 首层薄边丢失，子像素特征易消失 | Legacy 兼容基线，必须保留 |
| S1 | 层顶平面 + XY 中心点 | 简单，首层更宽 | 上表面收缩时会丢层，不表达整层体积 | 只作对照，不建议生产 |
| S2 | Z 层体积相交 + XY 中心点 | 解决半层相位偏差 | 仍会丢亚像素斜边 | 必做的分层候选 |
| S3 | Z 层体积 + 边界 2x2，覆盖 >=2/4 | 尺寸正偏差较小，接近外部参考 | 小于半像素覆盖的特征仍可消失 | 推荐首个生产候选 |
| S4 | Z 层体积 + 边界 2x2，任一命中 | 薄特征保存最强，参考总量最接近 | 外边界正偏差，可能增厚约半像素 | 保守候选，不直接默认 |
| S5 | 自适应 4x4 / 精确像素单元裁剪 | 覆盖率更精细 | 复杂度和性能成本高 | 研究备选，S3/S4 不足时才进入 |

设计原则：

```text
只融合正交语义：Z 层体积 + XY 覆盖率；
不融合“中心/顶部/底部 mask 全并集”等无物理合同的补丁；
不把形态学膨胀、最小线宽补偿混入基础几何占据。
```

## 4. 姿态候选方案

| 编号 | 方案 | 优点 | 主要风险 | 定位 |
|---|---|---|---|---|
| P0 | 现有确定性直角定向 | 稳定，13E/13G 已有矩阵 | 不消除残余滚转 | 继续作默认和回退 |
| P1 | 两个最低点强制着地 | 实现简单 | 对网格噪声敏感，曲边上不等于接触面积最大 | 拒绝作默认，只作负向对照 |
| P2 | 两侧边界带下包络平衡 | 对单个异常顶点更稳定 | 非对称甲片可被过度找平 | 可诊断的低风险候选 |
| P3 | 长轴限制下最大化前 1..2 层接触面积 | 直接优化工艺目标 | 需要稳定目标函数、角度限制和性能控制 | 推荐姿态候选 |
| P4 | 仅人工调平 | 操作员可控 | 不可批处理，结果不确定 | 必须保留的人工逃生口 |
| P5 | P0 默认 + P2/P3 显式 opt-in | 不破坏历史语义，可逐步收集证据 | 需要能力报告和 UI/Profile 暴露 | 推荐产品路线 |

任意调平候选必须同时满足：

```text
不缩放模型；
不根据文件名特判；
保持外表面 +Z 和尖端 +Y 合同；
首版只允许绕甲片长轴的受限连续角度；
使用边界带/接触面积，不使用单顶点直接决策；
报告请求角度、实际角度、接触改善和回退原因。
```

## 5. 当前推荐，不是生产授权

Stage 16 的首选研发路线为：

```text
采样：S0 保留 + S3 首个候选 + S4 保守对照；
姿态：P0 继续默认 + P2/P3 先诊断后 opt-in；
性能：先完成 telemetry/baseline，再优化 support/compose/provider/cache/parallel。
```

不得在 Stage 16-R4 之前宣布 S3/P3 为新默认。

## 7. Stage 14 后准入 Gate

16-00 必须逐项回答：

```text
G0-1 Stage 14 是否已有明确收口报告和稳定构建身份；
G0-2 Facade/SPI/Worker 是否会承载 Stage 16 配置和 telemetry；
G0-3 Stage 15 production Profile 和材料闭合基线是否仍可复现；
G0-4 segment_101 及外部 TIFF 参考是否允许作为版本化 fixture；
G0-5 外部 TIFF 的通道语义、层高和像素尺寸是否可以获得权威确认；
G0-6 新采样的产品偏好是尺寸忠实还是薄特征保存；
G0-7 是否存在可量化的甲片两侧接触/打印稳定需求；
G0-8 22 实例正式设备 SLA 和内存上限是否已冻结。
```

对 G0-4/5/8 回答为否不必然阻断全部 Stage 16，但必须将对应结论限制为工程候选，不得声称生产默认或设备 GO。

## 8. 固定红线

```text
不修改 p0.rgbwsv.2、RGBWSV 顺序、uint8 和 black_is_print；
不默认启用 OpenVDB，不用 OpenVDB 替换 Legacy production path；
不修改 Stage 15 补白、材料闭合、Model > Support 优先级；
不为 segment_101 文件名或单一网格写特判；
不用并行掩盖语义错误；
不在不同输出语义下直接对比性能；
不以顶点数、截图观感或单层像素总数单独决定生产 GO。
```

## 9. 回退原则

```text
采样候选必须显式 opt-in，S0 始终可用；
姿态候选必须先 diagnostic-only，P0 始终可用；
性能优化必须输出逐层/channel hash 一致性，失败即回退；
任何默认切换都必须经过独立 DOC_DECISION 刷新和显式授权。
```
