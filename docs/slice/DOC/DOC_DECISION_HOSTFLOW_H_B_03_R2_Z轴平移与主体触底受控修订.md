# DOC DECISION HOSTFLOW H-B-03-R2 Z轴平移与主体触底受控修订

> 状态：**IMPLEMENTED / VERIFIED**
> 日期：2026-08-18
> 范围：封装版宿主实例 Z 轴平移，以及含孤立微小组件 STL 的主体触底判定。
> 覆盖：本文受控替代 R1 中“任意 Z 平移不开放”和“以完整包围盒 `minZ=0` 作为触底成功”的条款。

## 1. 根因证据

`C:\Users\admin\Downloads\123.stl` 是 binary STL，原文件声明 41,270 个三角面，原始包围盒为：

```text
min = (-110.000000, -17.905098, -12.094902) mm
max = ( 110.000000,  42.094902,  11.786476) mm
```

连通组件检查得到 17 个组件。十个可见主体各有 3,362 到 5,500 个三角面，最低 Z 位于
约 `7.300..7.841 mm`；另有四个只有 12 个三角面的微小角标，尺寸约
`0.08 x 0.08 x 0.062 mm`，位于 XY 包围盒四角且最低 Z 为 `-12.094902 mm`。

R1 使用完整几何包围盒最低点触底，因此只把不可见角标放到了 Z=0，可见主体仍离平台约
`19.395 mm`。原真实资产测试也只断言完整包围盒 `minZ=0`，所以产生了假阳性。

当前模块的既有 STL 导入器会在建立 `SceneModel` 前过滤 12 个退化三角面；实测保留
41,258 个三角面，自动定向后的源包围盒已经是 `Z=0..4.48658 mm`。因此该真实资产在当前
Runtime 中无需再产生负向实例位移。主体触底算法仍按下述规则处理所有进入 SceneModel 的
显著连通组件，且由保留孤立微小组件的合成回归直接覆盖；不得把原文件三角面数误写成
实例变换阶段的保留数量。

## 2. 冻结语义

- 触底参考值由变换后网格的显著连通组件计算；组件共享精确顶点即连通。
- 三角面数不少于最大组件的 1%，**或**表面积不少于最大组件的 0.1%，即视为显著组件。
- 触底偏移取全部显著组件最低 Z 的相反数。微小组件不控制落点，但源三角形不被删除。
- 非零 Z 平移是显式人工意图，会关闭持久 `landOnBuildPlate`，避免提交后被自动拉回 Z=0。
- 显式“将选中实例触底”清零累计 Z 平移并重新启用持久触底。
- 手动 Z、自动触底偏移、权威包围盒、ViewData `worldMatrix` 与生产几何使用同一变换结果。
- Z 平移改变层覆盖，禁止套用仅适用于 XY 平移的 Raster 复用路径。

## 3. 合同与兼容

`contracts/slicer_capability_dtos.*` 从 v1.12 升为 v1.13：

```text
initialTransform += translateZMm（可选，默认 0）
translate.deltaMm = [x, y, z]
non-zero z => landOnBuildPlate=false
landOnBuildPlate => translateZMm=0
```

内部 scene schema 只增加可选 `translateZMm`，旧文档缺省按 0 读取。Z=0 时继续使用原
`slicesoft.model_transform.2` 哈希载荷，避免既有场景和缓存身份漂移；仅非零 Z 使用新载荷。
SPI v1、11 个导出、15 项能力、RGBWSV 通道、TIFF、Profile 和生产包协议均不改变。

## 4. 验证结果

- 合同 v1.13、核心变换、Scene Facade、XY Raster 复用拒绝 Z 变换和 Qt 控件定向测试通过。
- `123.stl` 经 Runtime 模块导入后保留 41,258 个非退化三角面；自动定向后的源几何及
  实例权威包围盒均为 `Z=0..4.48658 mm`，`worldZ=0`，可见主体落到 Z=0。
- 合成回归保留一个位于主体下方的微小孤立组件，验证该组件不控制落点、仍保留在输出几何中，
  主体最低点精确落到 Z=0。
- Runtime 宿主 `--self-test` 通过，SPI 仍为 1。
- 微小角标会保留在 Z=0 以下，但不生成负层；后续若要清理此类源资产噪点，必须另立
  网格修复策略，不得在本触底操作中静默删除。

## 5. 非目标与风险

- 不自动删除、焊接或修复 STL 连通组件。
- 不改变自动定向 SourceTransform、切片层原点或构建体积轴向。
- 阈值是确定性的宿主工作流保护规则，不替代严格模型拓扑预检。
- 用户手动下移到 Z=0 以下属于显式操作；UI 和权威包围盒必须如实显示，不静默再触底。
