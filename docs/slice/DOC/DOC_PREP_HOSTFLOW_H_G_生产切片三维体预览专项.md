# DOC_PREP HOSTFLOW H-G 生产切片三维体预览专项

> 状态：**PREPARED / DEFERRED**
> 日期：2026-08-10
> 归属：HOSTFLOW 宿主业务流程补充专项
> 当前结论：保留二维生产 TIFF 层预览为默认入口；三维切片预览另立 H-G 专项，不在本轮浅改 UI 中伪装完成。

## 1. 问题与目标

参考宿主当前拥有两类不同视图：

1. 模型工作区的俯视图和三维模型视图，数据来自 `SceneViewData`；
2. 结果工作区的二维生产层预览，数据来自严格校验后的 RGBWSV TIFF Package。

用户希望切片完成后，不仅按层查看二维 TIFF，还可从三维视角检查打印体内 RGB/W/S/V 的空间分布。该需求可实现，但不能把模型三维视图直接改名为“三维切片预览”，也不能仅堆叠少量 PNG 作为生产证据。

## 2. 冻结边界

- 不修改 `p0.rgbwsv.2`、RGBWSV 顺序、uint8 或 `black_is_print`。
- 不为三维预览额外生成逐层 PNG、网格或新的生产包文件。
- 不修改 SPI v1、11 个导出和 15 项能力。
- 只读取已经通过严格 Reader 校验的 Package。
- 二维生产层预览继续作为像素级权威视图和默认视图。
- 三维视图是检查工具，不得替代 RIP 校验或材料闭环报告。

## 3. 推荐产品形态

结果工作区提供分段视图：

| 视图 | 用途 | 权威性 |
|---|---|---|
| 二维生产层 | 查看单层 R/G/B/W/S/V 真值、像素探针和材料归属 | 像素级权威 |
| 三维层栈 | 查看选定层范围、材料通道和空间连续性 | 诊断视图 |

三维层栈首版采用 **2.5D 稀疏层栈**，而不是立即构建连续体素体渲染或等值面：

- 沿生产 Z 顺序加载 TIFF 层；
- 只为打印像素建立稀疏点、薄片或实例块；
- RGB 使用生产颜色，W/S/V 使用可配置伪彩；
- 支持通道开关、层范围、透明度、剖切和相机旋转；
- 缩放时按屏幕误差和内存预算做 LOD；
- 后台渐进加载，可取消，切换视图不阻塞 UI。

## 4. 数据与缓存合同

输入仅为当前结果页已经确认的 `packageDir`：

```text
manifest.json
layers/layer_XXXXXX.tiff
reports/*.json
```

缓存键至少包含：

```text
package identity
manifest hash
layer index range
enabled channels
preview LOD
```

缓存只存宿主运行期数据，不写回生产 Package。Package 变化、严格校验失败或层清单不连续时必须清空旧三维帧并显式失败。

## 6. 开工 Gate

H-G-02 开发前必须补齐并确认：

1. 单 Package 最大画布像素、层数和可接受峰值内存；
2. W/S/V 默认伪彩和混合优先级；
3. 三维视图是否显示空白区域、模型填充与支撑交界；
4. 大包的首帧时间、完整加载时间和取消响应目标；
5. CPU 稀疏层栈与 OpenGL 实例化两条候选路线的 Release 基准。

当前未满足上述产品和性能 Gate，因此本轮只完成专项建立，不将三维切片预览宣称为已实现。
