## 1. 决策摘要

本轮问题拆为两个专项，不把功能接线和大范围界面重排混在一次提交中：

```text
13B-08：批量导入、当前场景生产入口和场景切片编排；
13D：工作台信息架构、上下文检查器、诊断区域和高级工具收口。
```

执行顺序调整为：

```text
13B-08-01..04
-> 13C-03..05
-> 13D-01..04
-> 12E-09A-03..06
-> 12E-10A..D。
```

`13B-08` 插入 `13C-03` 之前。原因不是单纯的按钮视觉问题，而是当前代码在场景存在实例时
主动禁用旧的 `运行切片`，且 Qt 尚未接通 13B 多模型联合切片生产入口。用户看到三个模型后没有
可用切片动作，是当前产品主流程的真实功能断点。

`13D` 放在 `13C-05` 之后。13C 会收敛预览一级入口和数据源；若现在先重排整个工作台，随后还要
因 PreviewWorkspace 变化重复修改导航、尺寸和 Smoke。

## 2. 当前代码事实

### 2.1 切片按钮并非只是“不明显”

`MainWindow::UpdateActionAvailability()` 在 `SceneDocument` 存在实例时明确禁用
`run_slicer_button_`，提示“场景生产消费将在 13B 联合切片入口接通”。

`OnImportModelAndSlice()` 会重新打开单文件对话框并创建单模型配置，不消费当前三模型场景。因此不能
通过简单改按钮颜色或强制启用旧按钮解决，否则会绕过场景 identity、逐实例准入和联合写包。

### 2.2 批量导入尚未实现

`OnImportModelPreview()` 使用 `QFileDialog::getOpenFileName()`，每次只产生一个
`ModelTopViewLoadRequest`。`ModelTopViewLoader` 是异步单请求边界，当前没有批量队列、剩余容量检查、
逐文件结果汇总或批次结束后的单次自动排版。

### 2.3 右侧信息存在职责重叠

当前中央模型页右侧包含：

```text
模型列表 / 变换 / 排版。
```

主窗口最右侧又包含：

```text
参数 / 模型预检 / 诊断 / 工艺对比。
```

同时底部 `DiagnosticsDock` 已包含报告、材料闭环、曲线和日志。右侧“诊断”与底部诊断区存在入口
重叠；模型上下文编辑则被拆成两个相邻侧栏，压缩了画布宽度。

### 2.4 13B 核心能力已存在，但缺 Qt 产品接线

13B-05..07 已验证：

```text
MultiModelSliceOrchestrator；
SceneLayerComposer；
WriteMultiModelSceneProductionPackage；
1/11/12/22 实例功能矩阵；
单 Package、每层一个 TIFF、RIP strict。
```

缺口是把当前 `SceneDocument` 保存为不可变 Effective Config，执行 scene preflight，调用联合切片服务，
并把单 Package 结果回载到 Qt 工作台。不能把测试矩阵可执行文件直接当作 UI 生产服务。

## 3. 产品信息架构决策

### 3.1 P0 主流程

```text
导入一个或多个模型
-> 批量加载与结果汇总
-> 自动排版/手动变换
-> 当前场景预检
-> 切片当前场景
-> 自动加载单一输出 Package
-> TIFF 生产预览与诊断。
```

主动作固定为“切片当前场景”，必须始终可见；不可执行时保留按钮并显示具体阻断原因，不通过隐藏或
替换成单模型对话框回避问题。

### 3.2 工作台目标布局

```text
┌ 顶部作业栏：导入模型 | 保存场景 | 模式/Profile | 切片当前场景 ┐
├ 可折叠项目区 ┬ 中央工作区：模型 / 预览 / 配置 ┬ 上下文检查器 ┤
│ 路径与高级项 │                                  │ 场景/变换/排版│
│ 默认可收起   │                                  │ 设置/预检     │
├──────────────┴──────────────────────────────────┴───────────────┤
│ 可折叠诊断区：报告 / 材料闭环 / 曲线 / 工艺对比 / 日志         │
└─────────────────────────────────────────────────────────────────┘
```

中央模型画布不再同时被两个永久右侧栏挤压。上下文检查器只保留当前工作对象相关能力；运行日志和输出
诊断统一进入底部 Dock。

## 4. 阶段拆分

### 4.1 13B-08 场景作业流收口

```text
13B-08-01：批量导入队列、容量和结果汇总；
13B-08-02：Scene Production Service/CLI 显式入口；
13B-08-03：Qt“切片当前场景”主动作、预检和结果回载；
13B-08-04：真实模型矩阵、UI Smoke、用户说明和阶段收口。
```

### 4.2 13D 工作台布局收口

```text
13D-01：顶部作业栏和主动作层级；
13D-02：右侧 Context Inspector 合并模型编辑、设置和预检；
13D-03：项目/高级工具与底部诊断 Dock 重组；
13D-04：分辨率、中文长文本、键盘焦点和端到端 Smoke 收口。
```

## 5. 固定边界

```text
不重新启用旧单模型配置绕行当前 SceneDocument；
不把 multi_model_scene_matrix 当作产品运行入口；
不允许批量导入超过 22 个实例；
不允许部分失败被静默忽略；
不允许 Global 不支持时静默回退 Legacy；
不修改 p0.rgbwsv.2、RGBWSV、uint8 或 black_is_print；
不让 Qt 类型进入 slicer_core；
不因 UI 重排删除报告、日志、材料闭环或旧诊断能力；
不在 13D 中引入新的 3D 渲染第三方库。
```

## 6. 准入结论

```text
13B-08：应优先于 13C-03，需求边界明确，可进入任务级准备；
13C-03：保持 READY，但顺序后移，不撤销既有 PREP/PROMPT；
13D：总体设计可准备，代码开发等待 13C-05；
12E-09A/10：继续等待新的 13B-08 与 13C Gate。
```

本文已经用户确认，按 `13B-08-01 -> 02 -> 03 -> 04` 原子任务顺序开发、验证和提交。
