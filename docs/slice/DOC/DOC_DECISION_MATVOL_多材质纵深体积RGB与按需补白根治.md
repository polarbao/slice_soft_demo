## 1. 一句话裁决

现有 Legacy `relief_heightfield` 只保存每个 XY 列的最高三角面，并把该三角面的颜色沿整列实体传播，
不能表达同一列随 Z 变化的多材质所有权。MATVOL 新增显式、版本化、默认关闭的逐层材质所有权候选；
先支持封闭材质子网格，再以显式物理厚度候选支持开放表面。旧 Profile、旧输出协议和旧 Golden
必须逐字节保持不变，未经组合 Gate 不得替换生产默认。

### 2.2 生产链姿态下的实测事实（v1.4 更正，MV-08A 机器证据）

§2 与 §2.1 记录的逐材质拓扑事实来自 `MatvolFactsTests` 的极简 OBJ 解析器，
它**刻意不复用 `model.cpp`**「以避免自动定向等无关变换干扰事实固化」，
因此测的是**裸文件**而不是**生产链姿态**。MV-08A 用生产链口径（自动摆正 +
`AdaptSceneModelToTriangleMesh` 的 `1e-6` mm 顶点焊接）重测，结果与既有记录冲突：

| 资产 | 材质 01 | 材质 02 |
|---|---|---|
| `03.obj` | `closed_orientable`，14966 面，开边 0，自交 0，有向体积 125.816 mm³ | **`self_intersecting`**，12126 面，开边 0，**自交 8 对**，体积 157.397 mm³ |
| `08.obj` | 同上（面数与体积完全相同） | **`self_intersecting`**，12097 面，开边 3，**自交 8 对**，体积 156.173 mm³ |
| `09.obj` | 同上 | 与 `08.obj` 完全相同 |

**两条被推翻的记录：**

1. 「材质 01 为开放表面（1382 开放边）」**只在裸解析口径下成立**。那 1382 条边是 OBJ
   重复顶点造成的假象，`1e-6` mm 焊接后全部消失；在生产路径上材质 01 是**合格闭合体**。
   ⇒ MQ-01 壳层厚度与 MV-04 的 `surface_band` 对 `03.obj` **不再适用**——它没有开放表面。
   §4.2A 的间距趋零口径仍然有效，但其触发资产需另找。
2. 「材质 02 为闭合子网格（0 开放边）」在拓扑分类上**不成立**：它有 8 对确认自交。
   §4.2 已把自交列为阻断项且不得由壳层策略掩盖，因此
   **当前三个真实资产没有一个能通过 MATVOL 拓扑门**。

**这不是接线问题。** 阻断发生在 `BuildMaterialVolumePlan` 的拓扑分类阶段，
错误码 `E_MATVOL_TOPOLOGY_INVALID`，与 `slicer.cpp` 是否接线无关。
8 对 / 约 12000 面是极局部缺陷，且三个资产完全一致，指向系统性建模瑕疵而非随机噪声。
处置方向见 MQ-05。

### 2.3 自交处置裁定：无法自动修复，改为有界放宽（MQ-05 回签）

**能否自动修复：否。** 仓库的修复算子集合只有 7 个
（去退化面、去重复面、焊顶点、翻绕序、缝合边界环、填边界环、拆边扇），
**没有任何一个处理自交**；`ExecuteMeshRepairCleanup` 在确认自交时直接短路返回
`RejectedSelfIntersection`，不做任何改动。代码里有一句直白的自述：
`ProductionAdmissionPolicy.cpp:120` — 「Mesh repair is not implemented」。
文档亦多处明确「自动修复复杂自相交」为**非目标**，修复被推到产品之外的 DCC 工具。

**不修复是否影响切片策略：影响有界且可量化。** 实测：

```text
材质 02  12126 面  28450 候选对全部测完（complete）
         confirmed=8  coplanarOverlap=0  touchingOnly=0  aabbOnly=28442
逐列奇偶  0.100mm 覆盖 17755 列   奇数列 0
         0.042mm 覆盖 100678 列  奇数列 0   （600dpi 生产分辨率）
         0.021mm 覆盖 402670 列  奇数列 0   （2 倍生产分辨率）
```

**但奇偶完好不构成安全性证据。** 材质 02 的真开边与非流形边均为 0，即它仍是**闭合曲面**；
由 Jordan–Brouwer，闭合曲面与一般位置射线的交点数**恒为偶数**，
因此上述「奇数列 0」对本类是恒真的，只说明区间**形状良好**、不会触发
`E_MATVOL_INTERSECTION_UNPAIRED`。真正未被消除的风险是：自交处**缠绕数可能大于 1**，
而奇偶法则把双重覆盖判为外部，故**自交邻域内的材质归属可能错误**，
误差范围被那至多 16 个相交三角面的投影界住。

**裁定：有界放宽，不是无条件忽略。** 新增
`materialVolumePolicy.topology.selfIntersectionPolicy`，取 `reject`（默认，行为不变）或
`tolerate_closed_self_intersection`。后者的放行需**同时**满足三条：

1. 该材质仍是闭合曲面（真开边与非流形边均为 0）；
2. 自交对数不超过 `maxSelfIntersectionPairs`（默认 64）；
3. 放行材质名进入 plan 并由报告披露，不得静默。

**上限的作用是把放宽锁在「局部缺陷」。** 仓库中被判定「需重建」的资产自交对数为
`nai_you_new` 8409、`meigui_fudiao` 5592、`aishen_fudiao` 19270、`titian_fudiao/dmz` 48831，
与 `03.obj` 的 8 对相差三到四个数量级，远超上限，**仍然 fail closed**；
本放宽不构成对它们的旁路，也不改写 12E-08C 的历史结论。

**实测结果：** `03.obj` 在该策略下真正建出 plan——39267 段区间、27612 列、165 层，
放行名单恰为 `{02}`，逐列奇偶门一次未触发。把上限压到 4 对后按预期重新 fail closed。

**适用边界：** 用户 2026-08-24 明确当前模型仍非最终版本，故接受该有界放宽用于开发验证；
MV-10 生产准入前必须复核，届时若仍使用自交资产需单独回签。

### 2.4 MV-08B 实测：不存在内部空腔，间隙裁定的前提被推翻

**被推翻的前提。** MV-08B 实施前，本文档与我给用户的说明都把 `03.obj` 描述为
「两层薄壳、中间是空的」，并据此请用户裁定内部间隙语义（用户 2026-08-24 裁定
「间隙按不存在处理、确有间隙则填补为下层材料」）。该前提**错误**。

「两材质曲面最小间距 0.3008 mm」是**两张曲面之间的距离**，不等于「中间有空腔」。
实测表明两个材质是**上下叠置的闭合实体**：材质 01 有向体积 125.816 mm³、
材质 02 为 157.397 mm³，二者的区间并集覆盖了 relief 掩码标为模型的全部列与层。

**机器证据。** 按用户裁定实现的间隙填补逐列统计 `gapFilledCells`，
在 200 dpi 全部层上**恒为 0**；把策略改回 `reject` 后生产路径**照常跑完**，
未出现任何 `E_MATVOL_MODEL_PIXEL_UNOWNED`。两条独立证据一致指向：掩码与 plan 覆盖一致，
不存在未归属的内部体积。

**处置。** 据此撤除 `materialVolumePolicy.interiorGap` 整套机制
（配置、校验、宿主发射与层循环内的逐列填补）。理由是它落在逐层热路径上却**无法被验证**——
其唯一可能的测试是空断言，违反本专项一贯坚持的「变异必须命中」。
若将来出现确实带空腔的资产，重新引入的成本很低，且届时能带上真实的回归用例。
用户的裁定本身没有被否定，只是当前没有触发它的资产。

## 3. 根因裁决

1. MTL 解析和工作区表面显示正确；MeshLab 中的黄色不是 `03.mtl` 声明颜色。
2. 结果页默认组合 RGB/W/S/V，S 通道使用绿色伪彩色，不能用该组合判断 RGB 材质。
3. `ReliefColumnInfo::top_triangle_index` 每列只有一个材质事实；`build_material_role_columns()`

4. 开放表面没有天然体积，不能通过材料名或面颜色无歧义地推断内部归属。

## 4. 产品语义边界

### 4.1 新旧 Profile

```text
旧：全实体 RGB + 按需补白墨
    保持现有顶面颜色沿列传播语义，hash/输出不变。

新：多材质纵深 RGB + 按需补白墨（候选）
    显式启用 materialVolumePolicy；按层解析材质所有权；默认不生产准入。
```

不得把新语义静默塞进既有 Profile，也不得因检测到多个 `usemtl` 自动切路。

### 4.2 封闭与开放材质

| 输入 | 默认行为 | 候选行为 |
|---|---|---|
| 封闭、可定向材质子网格 | parity/有序交点形成体积区间 | 可进入生产候选 |
| 开放材质表面 | `fail_closed` | 仅显式 `surface_band` 候选 |
| 自交、非流形、重复反向面 | 阻断 | 不得通过壳层策略掩盖 |
| 未绑定材质或 MTL 缺失 | 阻断或显式 fallback | 不得静默继承相邻材质 |

开放表面壳层使用物理厚度 `thicknessMm`，离散为有效层数并写入报告。当前 `03.obj` 的绿色
开放表面采用多少厚度仍为产品输入；未确认前只能做诊断候选。

实测给出的**几何上限**：绿色面到浅桃色面最小间距 0.3008 mm，故 `thicknessMm <= 0.30` 时
绿色壳层在任何位置都不会侵入浅桃色 `02`。据此的推荐候选为 `thicknessMm = 0.228`
（0.038 mm 层厚下 6 层，留约 24% 余量）。该值仍为 MQ-01 待回签输入，未回签前不得写入生产 Profile。

### 4.2A 壳层厚度在间距趋零下的口径（MQ-01 回签后重做）

`thicknessMm` 的语义由「壳层厚度」改为「**请求的**壳层厚度」，是上界而非实际值。实际值必须
逐 XY 列按该列真实可用间距收敛，理由见 §9.1：固定常数在间距趋零时必然侵入另一材质。

**逐列收敛。** 对每个 XY 列，沿垂直射线取开放表面到该列上**下一个介入材质区间起点**的距离
`availableGapMm`（无介入材质时取到模型下界）。实际壳层深度取
`min(thicknessMm, availableGapMm)`，不再引入额外 epsilon——间隙的闭合端点归属由既有
闭合材质奇偶区间语义决定，另加 epsilon 会引入与区间模型不一致的第二套边界判据。

**层量化。** 输出按 `layerHeightMm` 分层，壳层只能落在整数层上：
`bandLayers = floor(min(thicknessMm, availableGapMm) / layerHeightMm)`。

| `bandLayers` | 该列结果 | 是否可能重叠 |
|---|---|---|
| `>= 1` | 壳层独占这些层 | **构造上不可能**，无需优先级参与 |
| `== 0` | 两材质落进同一层，Z 向无法区分 | **必然同层竞争**，由 `explicit_priority` 判定该层 owner |

`bandLayers == 0` 是 MQ-01 新约束暴露出的真实情形，也是本专项此前完全没有覆盖的分支。
它不是异常，而是「间距小于一个层厚」这一物理事实的必然结果，因此**不允许静默处理**：

1. 逐列计入 `collapsedColumnCount`，并按材质对记入 `material_volume_report`；
2. 该层 owner 由 `explicit_priority` 判定，优先级相同时按既有规则生产模式 fail closed；
3. 新增 `openSurface.collapsedColumnPolicy`，取值 `explicit_priority`（默认）或 `fail_closed`。
   默认取前者而非后者，是因为单个紧邻列不应否决整个作业；但塌缩列比例必须出现在报告里，
   使「大面积塌缩」可被发现而不是被平均掉。

**对 `03.obj` 的具体后果。** 该资产最小间距 0.3008 mm、层厚 0.038 mm，即最紧处仍有 7 层余量，
`bandLayers` 恒 `>= 1`，`collapsedColumnCount` 应恒为 0。这正好构成一条可断言的回归：
若 `03.obj` 出现任何塌缩列，说明逐列间距计算有误。反之需要另造间距小于 0.038 mm 的
synthetic fixture 才能覆盖 `bandLayers == 0` 分支，不能依赖真实资产。

### 4.3 重叠与优先级

多材质同时占据一个体素时必须由 Profile 提供显式优先级。禁止依赖 OBJ 面顺序、材料数组顺序、
hash 顺序或线程完成顺序。优先级相同且发生重叠时生产模式 fail closed。针对 `03.obj`，由于两材质
实测贴在薄壳相对两面、且在 `thicknessMm <= 0.30` 下**不产生重叠**，优先级在该资产上不会被触发；
仍按既有 `01` 优先（primaryPriority 200 > secondaryPriority 100）配置，作为超出上限时的确定性兜底。
该条款需通过 MQ-02 回签。

## 5. 按需补白兼容裁决

MATVOL 不直接复用现有 `materialRoleMapping.enabled=true` 路径，也不直接删除 Stage 15 的组合禁令。
新路径按以下顺序接线：

```text
当前层 model occupancy
  -> 当前层 material ownership
  -> MTL Kd / texture 解析为最终 RGB
  -> ApplyUnprintableWhiteCarrier(finalRgb)
  -> 同层 W 写入
  -> support/varnish/closure/report
  -> RGBWSV TIFF
```

按需补白只观察最终 RGB；不修改 RGB，不新增 Z 层，不触碰 S/V，也不新增 ownership mask。
绿色和浅桃色通常不命中严格纯白阈值；真实纯白/近白区域继续按既有阈值和值写 W。

## 7. 与 MEMFLOW 的依赖

MATVOL-01..05 可先建立纯合同、独立 oracle 和非生产候选；生产接线 MATVOL-06..09 必须消费
MEMFLOW 的 owned layer/单层物化能力。若 MF-03B4/MF-04 尚未完成，MATVOL 不得重新建立全层
材质 Mask 栈来绕过依赖。生产路由只能在作业开始前显式选定，不允许中途回退。

## 8. 准入与回滚

生产准入必须同时满足：旧 Profile 逐层 TIFF hash 零漂移；新 Profile 材质 owner/RGB/W 逐层 oracle
零差异；Package/RIP strict 通过；取消或错误不发布半包；峰值内存满足 RasterMemoryBudget；真实资产
报告无未裁决开放表面或重叠。

任何 Gate 失败时关闭 `materialVolumePolicy`，保留现有 Legacy 顶面投影路径。新增字段必须默认关闭，
旧构建遇到新 Profile 应 fail closed，不允许降级成旧全实体 RGB 后继续生产。

### 9.1 MQ-01 与 MQ-04 回签口径（2026-08-24）

**MQ-01：`thicknessMm` 不得作为固定常数写入生产 Profile。** 用户明确 `03.obj` 的 0.3008 mm
最小间距只是**当前这一个资产**的实测值，后续模型中两材质距离**可无限接近**。因此本决策
**撤回** v1.2 给出的 `thicknessMm = 0.228` 推荐值：任何固定常数在间距趋零时都会侵入另一材质，
「几何上限 0.30 mm」只是 `03.obj` 的性质，不是可推广的设计前提。

由此产生一条此前未识别的硬约束：输出按 0.038 mm 分层，**当两材质间距小于一个层厚时，
它们在该 XY 列上落进同一层**，Z 向排序在物理上无法区分二者。此时问题不再是壳层厚度，
而是同层内的所有权归属，必须由 `overlap.mode = explicit_priority` 判定。
MV-04 的设计据此重做，口径见 §4.2A。

**MQ-04：保持 `INPUT OPEN`，但不作为 MV-04..MV-09 的开工门。** 只有 MV-10 生产准入依赖它。
作为交换，MV-04 起每张卡都必须把实测耗时与峰值内存记入报告，等正式设备预算到位后直接比对，
不得等到那时再回头补测。
