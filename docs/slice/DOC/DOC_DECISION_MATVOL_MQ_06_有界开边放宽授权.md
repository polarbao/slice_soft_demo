## 1. 触发事实

用户用 `08.obj` / `09.obj` 切片时被拒，而 `03.obj` 可以通过，错误同为
`E_MATVOL_TOPOLOGY_INVALID: material '02' topology is self_intersecting`。

实测三个资产的逐材质拓扑事实后，差别**不在自交**：

| 资产 | 材质 02 自交对 | 真开边 | 非流形边 | 结果 |
|---|---|---|---|---|
| `03.obj` | 8 | **0** | 0 | 通过 |
| `08.obj` | 8 | **3** | 0 | 被拒 |
| `09.obj` | 8 | **3** | 0 | 被拒 |

三者自交对数完全相同。被拒的真实原因是 MQ-05 放行条件之一
`boundaryEdgeCount == 0`（闭合性）不满足。

**附带修复的诊断缺陷**：原错误消息只报分类名 `self_intersecting`，不说明放行为何被拒，
导致「同为自交，为何 03 可以」无法从消息本身判断。已改为附加具体原因，例如
`tolerance declined: surface is not closed (3 boundary edges)`。该改进不涉及授权。

## 2. 授权范围

新增 `materialVolumePolicy.topology.maxBoundaryEdges`，默认 **0**（保持现状，行为不变）。
显式设置为正数后，允许**真开边数不超过该上限**的材质进入区间求解。

放行仍需**同时**满足既有三条加本条：

1. 分类为 `self_intersecting`（`open_surface` 等其余非闭合分类不在本授权内）；
2. `selfIntersectionPolicy == tolerate_closed_self_intersection`；
3. 自交对数 ≤ `maxSelfIntersectionPairs`；
4. 非流形边数为 0；
5. **真开边数 ≤ `maxBoundaryEdges`**（本次新增）。

## 3. 为何本次放宽的依据强于 MQ-05

这一点必须写明，否则容易被误读为「又放宽了一次，越放越松」。

MQ-05 放宽自交时，本文档 §2.3 明确记录过：**对闭合曲面，由 Jordan–Brouwer，
一般位置射线的交点数恒为偶数**，因此「逐列奇偶完好」对那一类是**恒真条件**，
不构成安全性证据；当时真正的兜底是「范围有界且披露」。

本次不同。**开边一旦存在，Jordan–Brouwer 不再保证奇偶**，因此区间求解中既有的逐列
`E_MATVOL_INTERSECTION_UNPAIRED` 门在这一类上是**真检查而非恒真**，且在**真实生产网格**上
逐列精确判定并报出具体列位置。

⇒ 本次放宽的实质是把「开边数为 0」这个**代理指标**换成「逐列奇偶」这个**直接检查**，
保证不降反升，而不是单纯放松。

## 4. 未被消除的风险

- 逐列奇偶只保证区间**形状良好**（成对配对），不保证开边邻域内的**归属正确**。
  与 MQ-05 的缠绕数问题同理，误差范围由开边邻域界住。
- `maxBoundaryEdges` 是**局部性上限**，不是正确性证明。上限设得过大等同于取消该门。

## 5. 影响面

| 对象 | 影响 |
|---|---|
| 既有工艺与预设 | **无**。默认 0，未显式设置时行为与本次改动前逐字节一致。 |
| `03.obj` | 无影响，其真开边本就为 0。 |
| `08.obj` / `09.obj` | 在宿主预设显式设置后可进入区间求解。实测其材质 02 在 0.1 / 0.042 / 0.021 mm 三档分辨率下奇数交点列**恒为 0**（最多 385,319 个覆盖列）。 |
| 被判定「需重建」的资产族 | **仍然 fail closed**。它们的自交对数为数千至数万，远超 `maxSelfIntersectionPairs`，本次放宽不构成对它们的旁路。 |
| 生产默认 | 不变，`materialVolumePolicy` 仍默认关闭，新预设为显式 opt-in。 |

## 6. 披露要求

放行材质名必须进入 `material_volume_report` 的 `warnings`，与 MQ-05 同口径，不得静默。

## 7. 适用边界

用户已多次明确当前模型**仍非最终版本**，故接受本放宽用于开发验证。
**MV-10 生产准入前必须复核**；届时若仍使用带开边的资产，需单独回签。
