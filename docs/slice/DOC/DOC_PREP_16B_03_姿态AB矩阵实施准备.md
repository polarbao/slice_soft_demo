## 2. 姿态定义

```text
P0：现有确定性直角定向；
P2：根据两侧边界带下包络差计算一次平衡角，不用单个最低点；
P3：在 [-12,+12] 度内最大化前半层接触面积，受高度、占地、+Z/+Y 约束；
采样：S3，固定 2x2 且 >=2/4 子采样命中；
应用：绕 +Y 长轴旋转模型副本并重新落到 Z=0；不修改源资产。
```

## 3. 证据合同

`posture_matrix.json` 必须记录：

```text
接触面积及相对 P0 改善；
两侧包络差；
模型高度、X 占地及相对 P0 增量；
模型/支撑像素及相对 P0 增量；
同一 S3 core-only 是否准入/运行以及准入状态是否变化；
资产 hash、autoOrient 结果和 P3 候选评估次数。
```

标准甲片仅验证姿态算法零漂移；Reality 101..105 执行三姿态真实 S3 支撑切片。这样可避免把
标准甲片的高成本纹理写入链重复当作姿态证据。

## 4. 停止条件

任一姿态破坏 +Z/+Y、超过角度/高度/占地预算、core-only 失败，或结果依赖文件名特判时，本卡
失败。矩阵通过也不自动批准 P2/P3 进入生产；16B-04 仍需单独候选选择和用户授权。
