## 1. 授权与问题

用户确认 `gubao05` 中的定位小块只负责确定输出画幅，不要求真实打印；后续定位素材统一使用材质名 `nail-Default`。用户授权准备方案、独立拆卡并直接实施，允许按需并行。该授权包含生产几何分类的有限扩展，不包含修改 RGBWSV/T 协议、放宽真实打印模型拓扑准入或扩展 MATVOL 的 S3 适用范围。

旧实现把全部三角面作为打印几何，并据其范围建立 Raster。定位块因此同时扩展画幅并进入 MATVOL 材质层序解析；没有 `-L<n>` 后缀时触发 `E_MATOPQ_LAYER_NAME_INVALID`。给定位块补层号会令其打印，直接删除又可能缩小画幅，均不符合用户需求。

此次是横跨导入、变换、预检、单模型/场景 Raster 的几何用途合同，成立独立 FRAME 专项，不挤占 MATOPQ/MEMFLOW 原卡，也不由 Qt 临时裁剪或 Writer 清零掩盖。

## 3. 冻结合同

### 3.1 识别规则

1. 只对实际绑定到三角面的材质名进行精确、区分大小写的 `nail-Default` 匹配。
2. `Default`、`Nail-Default`、`nail-default`、`nail-Default-L1` 均不属于该保留名；不得靠前缀、子串、尺寸、颜色、不透明度或文件名猜测。
3. 定位保留名不是一种打印材料，不分配层号、priority、材料体积 owner 或通道；普通打印材质仍严格执行原命名和拓扑检查。
4. 同一定位材质可绑定多个不相连定位块。仅有未使用的 MTL 声明不应扩展范围。
5. 不改写源 OBJ/MTL；载入后的内部分类为唯一判据，并供重载 Worker 使用同一规则。

统计口径：源 `vertex_count`、`face_count`、UV 数量维持原始导入统计，OBJ 四边形的源面计数不能伪造为三角形数；`triangle_count` 为分离后可打印三角数，新增 `frame_triangle_count` 显式记录分离的定位三角数。`materials/material_infos` 只保留可打印材料，不把定位材质送入材料语义或外观校验。报告使用这些计数时应注明源统计与打印统计的区别，不能因源顶点数保留而宣称定位面仍参与打印。

### 3.2 几何与坐标

| 输入用途 | XY 画幅 | 打印 Z/层数 | 材料/纹理 | 白墨/光油/T | 支撑 |
|---|---|---|---|---|---|
| 普通打印面 | 参与 | 参与 | 原合同 | 原合同 | 原合同 |
| `nail-Default` 面 | 参与 | 不参与 | 不参与 | 不参与 | 不参与 |

定位顶点必须随主体应用相同的单位换算、自动定向最终变换、旋转、镜像、缩放、XY 平移和最终触底平移。不得单独居中或各自触底，否则定位图形与主体的坐标关系会漂移。

自动定向决策、主体触底参考、打印高度和层数从打印几何求取；定位块不得因处于最低点而把主体抬高，也不得因高 Z 而增加空白层。定位点经过相同变换后只取 XY 包围范围，与主体 XY 合并建立最终输出范围。定位几何不能通过包围盒替代实体占用 Mask。

无定位素材的模型必须保留旧行为。只有定位素材而没有打印几何时显式拒绝空作业，不生成“成功”的全空生产包。

### 3.3 验证与安全

分离必须早于打印网格诊断、材料层序解析、体积占用、支撑和场景合成；不能只在 `MaterialLayerNameResolver` 跳过一个名字。定位坐标仍需有限数值与索引合法性校验，非法定位数据不能造成 NaN、整数溢出或无限画幅。

打印三角面的拓扑诊断、strict admission、MATVOL overlap、材质闭合、输出包严格验证不放宽。定位保留名只让明确声明的定位几何退出打印准入对象，不让其他材质失败被吞掉。

所有定位独占像素在每层均应为“不喷墨”：生产 RGBWSV 空值仍为 255（`black_is_print`），不能误用 0。T 保持现有派生/协议口径，定位独占区域不得产生 T 请求，不新增 TIFF 通道或私有例外。

## 4. 实施分层

1. 核心模型层提供单一保留名判定；载入时将定位三角面从可打印 `triangles` 分离为 `ModelReport.frame_vertices`（定位顶点），同步移除其打印材质 `materials/material_infos` 与纹理绑定，避免索引错配。定位顶点保留任意后续实例变换所需的真实几何信息，不仅存源 AABB；旧调用接口尽量兼容。
2. 载入路径在定向决策之前获得打印/定位分类，定向最终矩阵同样作用定位数据；`ModelReport` 中保留可用于任意后续实例变换的信息。
3. `TransformedModelAdapter` 只对打印几何执行触底及投影有效性判断，使用同一最终矩阵变换定位信息；Scene 包围盒需明确 XY 范围与打印 Z 的不同来源。
4. 单模型核心 Raster 与 Scene 全局 Raster 均使用合并 XY 范围，层数来自打印高度。场景拼接裁剪、平移复用与实例 placement 不得重新缩回主体 bounds。
5. 宿主仍从权威模型/场景数据显示画幅与执行 buildVolume 校验；不在 Qt 重算打印几何。预检不能把定位材质当成缺失层号的打印材料。
6. Writer、RIP、Profile 身份、SPI/Worker 格式不因本专项改变。部署只在编译与门禁通过后执行，不替换用户正在使用的运行进程。

视图表现边界：定位块从可打印表面隔离后不再显示为实体打印表面，但包围盒保留定位后的 XY 范围。本轮不增加新定位图元、图层开关或 ViewData ABI 字段。若后续需要显式显示定位标记，应作为独立 UI 需求，不把定位三角面重新混入打印网格。

修复资产边界：现有 `DeterministicObjAssetWriter` 接收的 `AdaptedTriangleMesh` 不携带定位顶点，直接导出再重载会丢失画幅。FRAME 首版不扩展修复 OBJ 编码；在 `ProductionRepairFacade` 和 `slicer_cli --repair-asset` 的源模型加载后、适配及写盘前，对含定位几何的修复导出显式拒绝，不能默默只写主体。正常“多图层透明”切片不依赖该导出；`geometry.repair` 是独立可选能力。未来要支持含定位素材的修复导出，须单独增加定位信息无损往返 Gate。

以上为职责合同，最终文件名与具体内部 DTO 以实现和测试为准；不得为符合文档草案而强行改写现有边界。

## 4.1 大画幅空白列的保守剔除

FRAME 的真实 `gubao05` 600 DPI / 0.033 mm 验证暴露额外性能成本：定位素材扩大的 220 × 60 mm 画幅即使大部分为空，`MaterialVolumePlan` 现有逐列循环仍会遍历每种材质的全部三角面，再做单三角 XY bbox 比较。仅隔离定位面不会去除主体三角面乘空白列的成本。

本轮 FRAME-03 附属优化：复用已有 `triangleXyBounds` 与 `trianglesByMaterial`，对每个材质求所有已分组三角 bbox 的 XY 并集。在材质循环入口用与现有三角剔除完全相同的 `px < minX || px > maxX || py < minY || py > maxY` 跳过整材质空列。其后 hits、排序、共面合并、奇偶配对、层区间、priority 与重叠错误完全保持。

等价证明基线为**当前已经包含单三角 bbox 剔除的实现**：若点在某材质 bbox 并集的任一轴范围外，它对该材质每个三角都必然触发现有剔除，因此原 hits 必空，整材质跳过与原 `hits.empty()` 分支相同。不要把此结论误写为相对取消全部 bbox、只保留带 epsilon 重心判定的历史实现也完全等价。

边界约束：同一 double 顶点 extrema，不引入取整、epsilon 或像素 bbox；严格 `<`/`>` 保留闭区间边界；空材质组三角集合显式处理；只汇总实际分组的三角索引。保持拓扑验证、取消检查和逐列 interval offset 写入。新增内存为 O(材质数)，不建立逐层或逐像素材质 bbox 缓存。

验证增加负坐标、恰落材质 bbox 边界的像素中心、空背景/多材质 fixture，覆盖逐层 owner 与同画幅输出对照；完整真实包已验证主体通道和定位空白。优化前尝试被人工终止，没有完整基线，**不记录加速比例**。优化后完整切片/写包/报告为 82.3605 s，不含初始导入和随后独立严格 Reader；具体配置与证据见任务卡 §6。

## 5. 风险矩阵

| 风险 | 防线 |
|---|---|
| 只删除定位三角面导致画幅缩小 | 独立保存定位信息，验证单模型与 Scene 最终宽高 |
| 只存源 AABB，旋转后过度扩框 | 使用实际定位顶点/三角形求变换后 XY，不把源 AABB 八角当权威几何 |
| 定位 Z 改变触底、定向或层数 | 主体独立求决策，定位随同一最终矩阵，极端 Z fixture |
| 材质/UV 索引不同步 | 配对过滤与三角面绑定测试 |
| 主体下方支撑仍按定位占用生成 | 排除点位于不重叠区域、启用支撑，逐层检查 RGBWSV/T 全空 |
| Scene Raster 或 translated reuse 丢失扩框 | 单实例与多实例、XY 平移、旋转后包头与全局像素位置测试 |
| 诊断候选/预检复制模型后定位坐标仍是旧值 | 检查 `TransformedModelPreflight`、核心 transformed model 赋值和 `ContactLevelingAnalyzer::RollAndGround` 等副本路径；若候选不支持定位素材，须显式拒绝而非产生错位结果 |
| 普通 Default 被误忽略 | 普通名、近似名负例，严格层号错误保持 |
| 可选 repair 导出只写主体导致定位范围丢失 | 含定位几何的源模型在生产 repair facade / CLI repair 入口显式拒绝；不声称修复导出已支持 FRAME |
| 定位素材掩盖真实主体拓扑错误 | 主体非流形/重复面负例仍拒绝 |
| 扩大画幅导致内存/文件膨胀 | 保持现有 Raster 尺寸与预算检查，实测记录宽高、层数与耗时，不承诺定位免费 |

## 6. 验证与收口

- 单元：精确命名、近似名、无定位、纯定位、多个定位块、绑定完整性、非有限坐标。
- 变换：XY 平移、旋转/镜像/缩放、定位块极低/极高 Z、自动定向开关、触底开关；主体结果与移除定位但强制同画幅的对照一致。
- 生产：单模型和 Scene 的宽高/origin 与定位范围一致；打印层数不变；定位独占区域逐层 RGBWSV 全空，T 派生不喷墨，支撑不延伸至定位块。
- 材料：普通 `Default` 仍按原命名拒绝；真实主体 RGB、V、必要 W 和各层覆盖关系不漂移；MATVOL 固定 S0 不变。
- 真实资产：原目录 `model/obj/multi-material/gubao05`，工艺“多图层透明”，记录源文件哈希、有效 Profile、姿态、DPI/层厚、最终包目录、宽高/层数、错误码/退出码、RIP/包验证和像素检查结果。
