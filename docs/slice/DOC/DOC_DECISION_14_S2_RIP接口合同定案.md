## 1. 定案条款

### 1.1 S1 切片输出协议（冻结，不在本轮变更）

```text
协议       p0.rgbwsv.2
通道       6，固定顺序 R, G, B, W, S, V
位深       uint8
极性       black_is_print → printValue = 0（出墨）、emptyValue = 255（不出墨）
背景       模型外区域六通道全 255
planar     contiguous
存储       stripped（默认）或 tiled，manifest 声明
DPI        X 与 Y 可不相等
```

### 1.2 Q1 · W/S/V 墨滴量化【S】

**由 RIP 承担量化**（方案 A）。切片侧与打印软件**零改动**。

| 逻辑通道 | grayBits=2（默认）档位 | grayBits=1 档位 | 物理上限（2 / 1） |
|---|---:|---:|---:|
| White | **6** | **2** | 6 / 2 |
| Support | **9** | **3** | 9 / 3 |
| Varnish | **9** | **3** | 9 / 3 |

RIP 保证输出严格落在按通道上限内（尤其 **White ≤ 6**），不依赖下游静默钳位。

> ⚠️ 极性映射方向（输入字节 `0` / `255` 各自输出几滴）**不在本合同内** —— 见 §3.1。

### 1.3 Q2 · 白区语义：路径 D 定案【S】

**废弃 `WSV=000` 私有哨兵信号，统一改用真实材料语义。**

| 语义 | 六通道字节 | 物理含义 |
|---|---|---|
| **不透明白** | `255/255/255/`**`0`**`/255/255` | 无彩色墨 + **白墨打底** |
| 黑色纹理 | `0/0/0/255/255/255` | 彩色满墨（正常内容，不再被当作任何信号） |

**RIP 把 `255/255/255/0/255/255` 当作【普通白墨材料】处理，无需任何特殊识别逻辑。**

由此产生的三条推论：

```text
① 不存在"需要被下游剥离的假值"—— 每个字节都是真实材料指令
② 切片侧无需任何哨兵保护机制（见 §4 作废清单）
③ 合法纯黑纹理 0/0/0/255/255/255 恢复为普通内容，不再有碰撞风险
```

Stage 15 已在项目内提供该路径的自动 Gate 证据（`REPORT_15` §4.1）。

### 1.4 Q3 · 白色语义类型【S】

```text
同一层内【不需要】混用不透明白与透明白 —— 因此不需要逐像素区分，
p0.rgbwsv.3 协议扩展【不需要】，12G-TCWS 保持冻结。
```

作业级声明字段：

| 项 | 定案 |
|---|---|
| 字段名 | `whiteSemantics` |
| 取值 | `"opaque"` \| `"transparent"` |
| **权威源** | **manifest 为权威**，Profile 仅提供默认值 |
| **冲突处置** | 两处取值不一致 → **fail-closed 报错，不猜测** |

### 1.5 Q4 · TIFF 压缩【S】

| 项 | 定案 |
|---|---|
| RIP 是否支持 `Compression = PackBits (32773)` | **支持** |
| 落地节奏 | **分两步**：首版仍「默认不压缩、按需开启」；「默认开启」作为独立决策后续推进 |
| 若后续改默认开启 | RIP 侧已接受我方同期重新固化 golden 基线所需的一个独立验收轮次 |

> 采纳分两步的理由：改默认会使**全部既有 golden TIFF 的 SHA-256 失效**，且很可能需同期把
> LibTIFF 从 `GO_OPTIONAL` 切为默认后端。对方已明确两种节奏都可接受，我方取风险较低者。

### 1.6 Q5 · grayBits 传递【S】

```text
字段路径   profile.device.grayBits
缺失行为   fail-closed 报错 —— 不默认猜 2
```

### 1.7 Q6 · RIP 输出组织【S】

| 项 | 定案 | 依据 |
|---|---|---|
| manifest 含 `dropRange` | **可以包含** | 双方确认 |
| W/S/V ≤ 按通道上限 | **保证** | 双方确认 |
| 输出组织 | **每层一个多通道 TIFF**，命名 `rip_%06d.tif` | **S3 硬约束唯一确定** |

> 输出组织不是偏好：打印软件 `ChannelSplitter` 要求 `samplesPerPixel ≥ 7` 且使用
> `TIFFReadScanline` **逐行**读取（禁 tiled），「每层每通道一个文件」无法通过该校验。
> **两种模式不可混用。**

### 1.8 材料混合交互【S】

逻辑 Support 墨滴按 **6 : 1** 分流至 `{Support1,2,3}` 与 `{Varnish1,2,3}`：

```text
是否叠加     由打印软件配置决定
超限行为     钳位到 9
```

## 3. 不在本合同内的事项

### 3.1 R1 极性映射表 —— 转 RIP ↔ 打印软件双边【重分类】

**切片侧不持有该信息，也不需要它。** 理由：

```text
· 切片输出的 W/S/V 是二值字节（0 / 255），由 p0.rgbwsv.2 冻结，不因映射方向改变；
· 量化由 RIP 承担（§1.2）；
· 消费方是打印软件的 ChannelSplitter 与 S2 校验器，均不在切片仓库内。
```

**但该问题仍然存在且必须有人认领**，因为它是唯一"搞错也不报错"的失效模式：
打印软件对逻辑通道 4..6 **取值直接作为墨滴数**，若 RIP 直接透传切片语义，
会出现 `0`(出墨)→0 滴、`255`(空)→钳到上限，**输出等同一张底片**。

我方代拟条款如下，**请 RIP 侧与打印软件侧双边确认后回填本节**：

```text
grayBits=2:  W=0→6 滴   W=255→0 滴 ；S=0→9   S=255→0 ；V=0→9   V=255→0
grayBits=1:  W=0→2 滴   W=255→0 滴 ；S=0→3   S=255→0 ；V=0→3   V=255→0
```

**状态**：⬜ 待双边确认。**不阻塞切片侧任何工作**；阻塞 RIP 实现与 S2 校验器编码。

### 3.2 外部目标 RIP 的实机验收

Stage 15 的 G5 仅证明**本仓库** strict Reader 兼容，不等同外部目标 RIP 已完成集成验收。

## 4. ⛔ 已作废方案 —— 禁止实现

选定路径 D 后，以下为**路径 A 的配套设计**，全部失效。若在任何文档中仍见到，以本节为准。

| 作废项 | 原出处 | 作废理由 |
|---|---|---|
| **保护一 · Writer 断言**<br/>写出前扫描 `W==0 && S==0 && V==0` → fail-closed | `DOC_ANALYSIS_14_Q2` §2.1.4 | 路径 D 下不存在哨兵，无需保护 |
| **保护二 · manifest `ripBoundIntermediate`**<br/>`{ whiteRegionSentinel: "WSV=000", contractId: "rip_bound_intermediate.1", ... }` | 同上 | 同上。实现它会把已废弃概念固化进 manifest |
| 路径 A（保留 `WSV=000`） | `DOC_CHECKLIST_14` §2 Q2 | 已由 R3 选择路径 D 取代 |
| 路径 B（全 255 表示白） | 同上 | 与背景字节相同，Stage 15 已实证为致命 |
| 路径 C（RGB 黑哨兵 + 全链路转义） | 同上 | 对方明确不接受（Q2.7） |
| 路径 E（`WSV=000` + RGB 载色） | 同上 | 路径 D 已定案 |
| 逐层 1-bit sidecar | `DOC_CHECKLIST_14` v1.0 | 用户否决（会要求 RIP 重做） |
| `p0.rgbwsv.3` 协议扩展 | Q3 讨论 | Q3.1 确认同层不需混用，不必扩展 |

**`DOC_ANALYSIS_14_Q2` §2.1（`WSV=000` 结构性不可达论证）保留为历史材料**，
它证明了路径 A 的安全性 —— 但路径 A 未被选用，该论证不再具有实施意义。

### 4.1 ⚠️ 不要误删：`PM-SLICER-CONTRACT-0060` 本身有效

该错误码是 **SPI 既有通用错误码**，语义为「自检发现产物不符合 `p0.rgbwsv.2`」，
定义于 `INT_07` §错误码表与 `INT_02` §6，**与 Q2 白区议题无关，必须保留**。

```text
⛔ 作废  用它承载「WSV=000 哨兵扫描」这一特定用途
✅ 保留  错误码本身及其既有「产物自检不符契约」语义
```

同理，`INT_07` / `INT_02` 中的 SPI 错误码表**整体有效**，不因本轮 Q2 定案而变更。
