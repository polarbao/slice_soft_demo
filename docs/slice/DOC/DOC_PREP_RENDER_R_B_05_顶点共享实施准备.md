## 1. 目标与边界

当前 `SceneViewMeshBuilder` 为每个三角面写入三个独立顶点。R-B-05 在不修改
SPI v1、11 个导出、15 项能力和生产 TIFF 协议的前提下，将完全相同的
`position + normal + uv` 顶点复用为一个索引顶点。

本卡不做以下工作：

- 不按 epsilon 焊接位置，不修复拓扑；
- 不跨 UV 缝或法向缝合并顶点；
- 不改变材质组、三角顺序和 `uint32` 索引格式；
- 不引入 `meshoptimizer`，不实现 R-B-01/02/04；
- 不修改 `apps/slicer_debug_ui/**`。

## 2. 冻结实现合同

1. 去重键使用最终写入 DTO 的八个 `float` 分量：位置 3、法向 3、UV 2。
2. 正零和负零规范为同一位模式；其他值按精确位模式比较，不做近似比较。
3. 首次遇到顶点时按既有材质组、三角面、三角顶点遍历顺序写入缓冲区；后续只复用索引。
4. 去重表可跨 submesh 使用，因为材质归属由索引区间表达，不属于顶点属性。
5. 同一几何位置只要 UV 或法向不同，就必须生成独立顶点。
6. 预算统计继续读取实际 `positions/normals/texcoord0/indices` 字节数，无估算旁路。

## 3. 验收矩阵

| 用例 | 期望 |
|---|---|
| 共面纹理四边形 | 2 三角由 6 个独立顶点降为 4 个共享顶点 |
| 同位置 UV 不同 | UV 缝保留两个顶点，不能被焊接 |
| Debug/Release provider | ViewData 闭合、identity 与预算正常 |
| Debug/Release 参考宿主 | 顶层 `meshes[]` 可解析并渲染 |
| 14E-04c 三维合同 | 三维渲染合同保持 PASS |

目标 `约 28 B/三角` 是大型连通且可共享网格的估算，不作为单个 fixture 的硬编码结果。
真实甲片收益必须由后续 R-A-02 对冻结的 36 模型矩阵重新测量。
