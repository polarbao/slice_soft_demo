# DOC DECISION 13F 多模型交互、取消与切片性能稳定化专项

> 文档版本：v1.1
> 文档状态：APPROVED / INSERTED
> 决策日期：2026-07-29
> 最近更新：2026-07-30
> 触发来源：真实多模型导入、密集模型选择、场景切片取消及 Reality 模型耗时反馈

## 1. 决策

在 Stage 13 多模型生产链路中插入 13F 稳定化专项，分两批执行：

```text
13F-R0：修正增量导入展示、密集模型选择、外部进程取消生命周期；
13F-R1：建立单实例核心切片计时、内存预算和重复实例加速基线。
```

13F 不改变 RGBWSV TIFF 协议、材料优先级、自动定向候选排序和生产输出语义。
自动定向启用后将最终候选归一化到构建平台 `minZ=0`，属于既有落台合同修复，
不属于新增旋转策略。

## 2. 已确认问题

### 2.1 批量导入仅显示前缀

批量导入期间，UI 曾把可见实例数冻结为批次开始时的数量。后续模型即使已经完成
导入并进入 `SceneDocument`，也要等整批结束后才能显示。高面数模型加载较慢时，
用户会长期看到“只显示前三个”的状态。

### 2.2 密集模型选择卡顿

旧命中测试在 UI 线程逐三角形检查鼠标点。爱神真实模型约从 4.1 万面到 28.3 万面，
选择密集模型时会放大为明显卡顿；切换当前实例还会重复深拷贝预览与三角形数据。

### 2.3 取消与进程状态分离

旧实现调用 `QProcess::terminate()` 后立即把控制器标记为已取消。Windows 控制台进程
可能仍继续运行，导致日志继续输出、`m_processBusy` 不释放、切片按钮无法恢复。

### 2.4 Reality 模型切片耗时

Reality 五个资产已按用户授权纳入 `model/obj/reality`。单个模型约 1.3 万至 1.5 万面，
并不比爱神模型更密集。Release 检查确认首个模型物理高度仅 `6.9752 mm`，但源坐标
位于 `Z=303.731..310.706 mm`。旧自动定向在模型已满足最大高度时直接返回源
`identity`，切片层数因此按绝对 `maxZ` 计算为约 `8177` 层，而不是按物理高度计算为
`184` 层。这是未落台造成的层数和内存膨胀，不是 XY 排版位置、三角面数量或 TIFF
保存速度导致。

修正后，自动定向仍选择 `identity`，但有效包围盒归一化为 `Z=0..6.9752 mm`。同一
Release 配置下，核心计算为 `1348.5702 ms`，完整 TIFF/preview/report 写包总耗时为
`3719.056 ms`，严格 RIP Reader 校验通过。

## 3. R0 实现边界

```text
批量导入每完成一个实例即扩大可见范围；
优先使用缓存 surface preview alpha 做常数时间命中测试；
没有 surface preview 时才回退到逐三角形命中；
消除选择切换前的一次冗余 SceneViewGeometry 深拷贝；
取消进入 Cancelling 状态，等待真实进程退出后才进入 Cancelled；
terminate 后 1 秒仍未退出则 kill；
取消后的残留输出不加载为生产 package；
进程退出后恢复切片操作。
```

## 4. R1 后续任务

```text
为每个实例输出 modelId、grid、layerCount、coreSliceMs、composeMs；
建立相同 Profile、相同 Grid、关闭 TIFF/preview/report 保存的核心基准；
评估平移重复实例的 raster 复用；
评估有内存上限的有限并行，禁止直接按实例数无限并发；
为导入阶段记录 parse、texture、surface preview、hash 分项耗时；
根据面数和纹理分辨率采用自适应预览精度。
```

Reality 单模型基准和 Z 基准修复已完成；其余 R1 可观测性、预览精度、复用和有限并行
任务仍按任务清单继续，不因本次单模型恢复而自动关闭。

## 5. 验收

```text
五个爱神模型在各自导入完成后逐个进入俯视图，不再冻结在前三个；
密集模型命中优先走 preview alpha，不再逐次扫描全部三角形；
取消后 2 秒内进程退出，日志停止，切片按钮恢复；
取消不会自动加载不完整 package；
Reality 性能验证每次最多处理一个模型，并先记录有效配置；
启用自动定向且模型无需旋转时，有效包围盒仍必须满足 `minZ=0`；
所有性能结论区分核心切片时间与 TIFF/preview/report 保存时间。
```

## 6. 非目标

```text
不在 R0 引入后台 GPU 渲染；
不在 R0 并行执行多个完整切片器；
不根据文件名为 Reality 或爱神模型写特判；
不为 Reality 文件名、绝对 Z 偏移或单个模型编写专用特判；
不把“面数较少”直接等价为“切片一定更快”。
```
